# `models/` — canonical, de-duplicated model files

Single source of truth for benchmark model files. Suites do **not** copy or
symlink models; their job manifests reference files here by path.

Layout is two-tier — **tier 1 = format, tier 2 = source**:

```
models/
  bngl/      <source>/   BioNetGen Language sources
  net/       <source>/   pre-generated reaction networks
  antimony/  <source>/   Antimony sources
  sbml/      <source>/   SBML XML
```

Some tier-2 buckets name a single provenance — `models2/` (BioNetGen
distribution), `rulehub/` (RuleHub), `pybnf/` (PyBNF examples), `ssys/`
(Antimony corpus), `curated/` (the house-curated `wshlavacek/BNGL-Models`
collection). The remaining buckets — `bngl/{ode,ssa}` + their `net/*`
counterparts, and `bngl/nf/` — hold a curated, **mixed-provenance** corpus
assembled for a suite role; **Per-model provenance** below gives the
source-per-model breakdown for those.

| Bucket | Holds | Driven by |
|--------|-------|-----------|
| `bngl/ode/`, `net/ode/`   | 47 ODE benchmark models (BNGL + pre-generated `.net`) | `suites/ode/` |
| `bngl/ssa/`, `net/ssa/`   | 7 SSA stochastic models with no curated record | `suites/ssa/` |
| `bngl/curated/`, `net/curated/` | 8 BNGL-Models records — every BNGL model the manuscript names | `suites/ssa_table5/` (8), `suites/ssa/` (5), `suites/psa/` (3) |
| `bngl/nf/`                | 11 network-free (NFsim) models | NFsim parity |

The `.net` files were all generated by **BNG 2.9.3**; files from BNG
2.3.1 carry `scaledUpSpecies`/`lambda` artifacts that crash
`run_network`. Regenerate with `perl BNG2.pl model.bngl` — except the
`curated/` bucket, which has a script (below).

## `curated/` — the models the manuscript names

Every BNGL model the manuscript names by title has to come from the
house-curated `wshlavacek/BNGL-Models` collection. `bngl/curated/` holds
those eight records verbatim; `net/curated/` holds the reaction networks
generated from them, which `suites/ssa_table5` (all 8), `suites/ssa` (5)
and `suites/psa` (3) all read — **one artifact per model, no per-suite
copies**. `curated_nets.json` is the manifest: the record each model
comes from, the sha256 of the upstream `.bngl`, the sha256 of the
generated `.net`, its species/reaction counts, and any relaxation.

```sh
python regenerate_curated_nets.py --check          # are the committed .net files current?
python regenerate_curated_nets.py                  # rebuild them from the vendored .bngl
python regenerate_curated_nets.py --sync-sources   # re-copy the .bngl from $BNGL_MODELS_ROOT first
```

Generation strips every action **except `generate_network`**, so a
record's own simulate protocol never runs — the horizons belong to the
suites, and several records declare a different one for their own
protocol. Keeping `generate_network`'s options is load-bearing: the prion
record raises `max_iter=>150` over BNG's 100-iteration default so its
chains reach the model's own `max_stoich=>{PrP=>120}` cap, which is the
entire difference between its 121/3843 network and the 104/2809 one a
superseded vendored copy froze.

### Relaxation

A model may also declare a `relax` step, run before the `.net` is written
so the artifact carries the relaxed state as its seed. Only `gene_bursts`
does: its protocol — in the record and in the superseded source alike —
relaxes deterministically and carries that state into the stochastic run,
never simulating from the bare `0/0` seeds, and at Table 5's
one-cell-cycle horizon the unrelaxed model measures the basal regime
(12.5 % of replicates fire zero reactions).

Two rules keep this from becoming a place to hide hand-tuning:

- **The horizon must be converged**, so the seed is a steady state — a
  property of the model — rather than a point on a transient. Each
  declaration's `why` records the evidence; `gene_bursts` gives the same
  state at 3.6e5, 3.6e6 and 3.6e7 s.
- **The seeds are rounded to whole molecules.** An ODE endpoint is a real
  number, and engines do not agree on what a fractional molecule count
  means: bngsim and `run_network` both round, but RoadRunner's gillespie
  takes 0.389 literally and walks the species negative — the same failure
  that got Smith2013/474 dropped from the corpus. Integrality is settled
  in the artifact, where every engine reads the same number.

Before this bucket existed, `suites/ssa_table5`, `suites/psa` and
`suites/ssa` vendored **separate** pre-generated copies that had drifted
from the records and from each other — three copies of `tcr_signaling`,
three different sha256s — so a benchmark re-run faithfully re-measured
superseded networks.

## Per-model provenance

Provenance for the curated `bngl/{ode,ssa,psa,nf}` buckets, cross-referenced
against the pinned upstream corpora. The `sbml/README.md` file documents the
two vendored SBML models to the same standard.

### Method & pinned sources

Each vendored file's SHA-256 was matched against three pinned upstreams
(commit + per-file SHA-256 recorded in
`parity_checks/bng_parity/manifest.json`) and the BioNetGen distribution:

| Source | Repo / distribution | Pin | License |
|--------|---------------------|-----|---------|
| RuleHub | `RuleWorld/RuleHub` | `479d6d62` | MIT |
| RuleMonkey | `richardposner/RuleMonkey` | `0f701125` | MIT |
| BNGL-Models | `wshlavacek/BNGL-Models` | `81c90d8f` | CC-BY-4.0 |
| BNG2 Models2 | BioNetGen 2.9.3 distribution | `2.9.3` | MIT (© J. R. Faeder) |

**Match** column:

- `=` — vendored file is **byte-identical** to the cited upstream copy.
- `~` — **same model**, vendored copy lightly adapted (comment/formatting/
  rate-law edits during vendoring); the cited path is the upstream of record.
- `✎` — **curated** for this benchmark: no byte/name match in a pinned
  corpus. These carry their citation and source note in the file header
  (e.g. adapted from the NFsim distribution, the BioNetGen test suite, a
  RuleBender workspace, or the Lin–Feng–Hlavacek 2019 *J. Chem. Phys.*
  stochastic-benchmark set). The **Provenance** column records the citation.

> **Note — multi-homed models.** Many canonical BNGL example models appear
> byte-identically in more than one upstream (the BioNetGen distribution's
> tutorial models are mirrored in RuleHub; the "bunching" pair below is
> byte-identical in *both* RuleHub `Published/Hlavacek2018Restructuration/`
> and BNGL-Models `my_models/ode/`; the `pybnf/` files are byte-identical to
> RuleHub's `Published/PyBioNetGen/` mirror). The table lists one upstream of
> record per file; a `=` means byte-identity to *that* copy, not exclusivity.
