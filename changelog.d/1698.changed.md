- **What bngsim is, said where a search or an AI agent reads it first ([#1698](https://github.com/lanl/bngsim/issues/1698)).** The PyPI summary, the module docstring, the documentation's front page and `llms.txt` called bngsim an engine for BioNetGen reaction networks, which tells a caller holding an SBML or Antimony model to look elsewhere. Each now says it simulates SBML, Antimony and BNGL models, and the package lists keywords for the first time. Near its top, the README has a table of tasks: what bngsim does, what it does not (adjoint sensitivities; models with `delay()`, an algebraic rule or a fast reaction; a graphical interface), and which other tool to use there. A short "Choosing settings" says when compiled code, the linear solver's override, threads for many sensitivities, KINSOL for steady states, PSA and the JAX bridge apply. The quickstart said PSA preserves Gillespie statistics: it keeps the ensemble mean but inflates the fluctuations, and now says so.
