- **The PyPI summary, the module docstring, the docs front page, and `llms.txt` now say that bngsim simulates SBML, Antimony, and BNGL models ([#1698](https://github.com/lanl/bngsim/issues/1698)).** They used to call bngsim a simulation engine for BioNetGen reaction networks. The package now has keywords. The README is shorter and links to two new docs pages: "When to use bngsim", a table of tasks and alternatives with tips on compilers, solvers, sensitivities, steady states, SSA vs. PSA, NFsim and RuleMonkey, and JAX; and "What bngsim does", the feature list that was in the README. The quickstart no longer says that PSA preserves Gillespie statistics. PSA preserves means, not variances.
