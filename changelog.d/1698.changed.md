- **The PyPI summary, the module docstring, the docs front page, and `llms.txt` now say that bngsim simulates SBML, Antimony, and BNGL models ([#1698](https://github.com/lanl/bngsim/issues/1698)).** They used to call bngsim a simulation engine for BioNetGen reaction networks. The package now has keywords. The README has a new table on when to use bngsim and when to use another tool, plus tips on compilers, linear solvers, sensitivities, steady states, SSA vs. PSA, NFsim and RuleMonkey, and JAX. The quickstart no longer says that PSA preserves Gillespie statistics. PSA preserves means, not variances.
