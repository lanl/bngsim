- **What bngsim is, said where a search or an AI agent reads it first ([#1698](https://github.com/lanl/bngsim/issues/1698)).** The PyPI summary, the module docstring and the documentation's front page called bngsim an "embeddable simulation engine for BioNetGen reaction networks", which tells a caller holding an SBML or Antimony model to look elsewhere. Each now says it simulates SBML, Antimony and BNGL models, and the package lists keywords for the first time. The README opens with a table of tasks: what bngsim does, what it does not (adjoint sensitivities, models with `delay()` or algebraic rules, a graphical interface), and which other tool to use there.
