- **SED-ML time courses that output after their `initialTime` restarted the model at `outputStartTime` (issue #1493).** `read_sedml`, `read_sedml_protocol` and the OMEX loaders took `outputStartTime` as the start of the run, so a decay with `initialTime=0` and output from 5 reported A(5) = 1 where it is exp(-5); 19 of the 992 BioModels SED-ML files do this. `EvaluationSpec` and the protocol's `Experiment` carry a new `output_start`, the run integrates from `initialTime` and returns only the output window, and the writers emit both times. A BNGL actions block, which has no output start, writes such a run as `sample_times` from the initial time, with a warning. L1V4's `numberOfSteps` is now read, where every V4 document got 101 points.
