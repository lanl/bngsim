- **The initial-condition seeding follows `save_concentrations()`, and three steady-state columns are refused** ([#704](https://github.com/lanl/bngsim/issues/704)). Once `save_concentrations()` has made the state its own baseline, no parameter sets it, but a forward-sensitivity run was still seeded from the model file: dY/dA0 came back `[1/3, 2/3]` at the steady state of `A <-> B` for an `A(0)` that `A0` does not set. The seed is retired, for `run()`, `steady_state()` and `Model.effective_ic_sensitivity`. A fixed species that a parameter sets, `$A() A0`, now moves what reads it in a masked steady-state solve (`[0, 0]` for `[1, 2]`). `steady_state(sensitivity_params=...)` refuses a parameter that sets a conserved amount on a state a `run()` advanced (0 for 1/3), every column on a state a `run()` advanced and a caller then assigned to (1.555 for 2.003), and every column of a model whose conservation law spans compartments of different size (#758: -0.286 for -0.367).
