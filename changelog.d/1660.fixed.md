- **A `run_batch` row, or a `parameter_scan` or `bifurcate` point, was held to the default atol of the state the call was made from, not the one it started from ([#1660](https://github.com/lanl/bngsim/issues/1660)).** A row that doses a growing species decades below the model's value was held to a tolerance above that species, with no warning: a logistic grower declared at 1, dosed at X0 = 1e-9, returned X(20) = -4.6e-7 for 0.327 (-1.5e+292 at `n_points=41`), and a continuation scan of X' = -X returned -1.25e-8 for 2.06e-9. A scalar atol, the default or one passed, is now also read from each row's own start, as `run()` reads it, and each species takes the tighter of that and the model's reading, so no row is held looser than before; AtolScaleWarning reads the tolerance each row ran at. `atol="auto"` is still one vector per call, but each species takes its smallest scale over the rows' starts, not its scale in the live state, which gave the same -4.6e-7; `steady_state_batch`'s does too. A batch reads the model's side at its initial conditions, not where a run left it.
