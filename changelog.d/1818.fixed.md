- **`method="nfsim"` returned a frozen trajectory, with no error, once NFsim's total propensity was not finite ([#1818](https://github.com/lanl/bngsim/issues/1818), [#1788](https://github.com/lanl/bngsim/issues/1788)).** NFsim keeps the total as a running sum, so one non-finite propensity makes it NaN for the rest of the run, and NFsim then fires nothing. That happens when a rate law is NaN in the model's own state (`B -> 0` at `sqrt(k)`, k = -1, which `ssa` and `ode` refuse), and when NFsim reads a rate law partway through a firing: `kgap*(1+9*Xp/Xtot)` with one X is 0/0 while X is out of the observables, though every state the model reaches is finite (RuleWorld/nfsim#115, not yet fixed in the vendored NFsim). `NfsimSession.simulate`, `step_to` and the one-shot run now raise, naming the reactions whose propensity is non-finite, or, when each is finite again and only the running total is not, saying how that comes about. A session that raised refuses to advance until `initialize()`, since its state is the one NFsim stopped in, not the state at the time reached. A model whose propensities stay finite runs as before.
