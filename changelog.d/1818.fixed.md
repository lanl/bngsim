- **`method="nfsim"` froze, with no error, when a function rate law divided by an observable a firing empties for a moment ([#1818](https://github.com/lanl/bngsim/issues/1818)).** NFsim read rate laws while a firing had its molecules out of the observables: with one X, `kgap*(1+9*Xp/Xtot)` was 0/0 there, the NaN stayed in NFsim's running total, and every later row repeated the state at the first X firing, though each state the model reaches is finite. The vendored NFsim now carries the upstream fix (RuleWorld/nfsim#117), and the model agrees with `ssa` on its network. A NaN that is the model's own (`B -> 0` at `sqrt(k)`, k = -1, [#1788](https://github.com/lanl/bngsim/issues/1788), or a rate dividing by a count that reaches 0) is now refused by `NfsimSession.simulate`, `step_to` and the one-shot run, naming the reactions, where it was returned as a frozen run. Found after a step, the session refuses to advance until `initialize()`, as it now does after any error raised inside a step, which leaves a firing partway done; found before any step, it is left as it was.
