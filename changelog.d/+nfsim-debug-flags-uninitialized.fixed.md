- **A network-free run with connectivity on no longer reads three uninitialized NFsim flags.** NFsim's `System` constructors leave `trackConnected`, `printConnected` and `trackRxnNumber` unset; only NFsim's own command line sets them. Whatever the heap held could turn on per-firing debug logging to files that were never opened, which slowed runs and is undefined behaviour; under the sanitizers it stopped six connectivity tests every night since [#1818](https://github.com/lanl/bngsim/issues/1818) ([#1816](https://github.com/lanl/bngsim/issues/1816)). bngsim now sets all three to false when it loads a model.
