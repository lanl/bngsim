- **A pull request that adds a test file no check runs now gets a warning ([#1764](https://github.com/lanl/bngsim/issues/1764)).** `mir.yml` and the three Windows workflows run hand-picked test lists, and the `python-tests` legs build without what they have (MIR, MSVC, KLU on Windows), so a new file that only does real work there skipped on every leg, ran nowhere else, and left every check green. A new `python-tests` job, "New test files run somewhere", reads every leg's per-file counts and every other workflow's pytest lists (`ci/new_test_coverage.py`). It warns, on the checks page and naming the file, when the pull request adds a test file that skipped on every leg and that no list names, and it says which workflows' lists it could join. It warns rather than fails, since a new file may skip everywhere for a reason. `forced-jit` and `sanitizers` run the whole suite, but nightly, so they do not count as running a file on its pull request.
