- **An ODE run whose solution leaves through minus infinity in finite time returned a number near -1e286, with no error, when the species was declared at 0 or above ([#1679](https://github.com/lanl/bngsim/issues/1679)).** `X' = -(1 + X^2)` from `X = 1` is `tan(pi/4 - t)`, with no value from `t = 3*pi/4` on; a run to `t = 3` returned `X(3) = -3.5e+286`, where the same law with `X` declared negative, or run to plus infinity, was refused. Once `X*X` overflowed, the non-finite retry (GH #135) read `X` at 0, where the law is -1, and the run carried on. An overflow that is finite one atol below 0 is not an edge at 0, so such a slot now keeps its value and CVODE cuts the step: the run fails at the blow-up, naming the law. An overflow that reaches up to 0, as `exp(-1/S)` does, is read at 0 as before.
