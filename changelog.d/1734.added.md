- **The test suite now validates the SED-ML bngsim writes against the SED-ML L1V3 schema ([#1734](https://github.com/lanl/bngsim/issues/1734)).** #1677's schema failure, in every archive `net_to_omex(bngl=...)` made, was found by hand with `xmllint`. `test_sedml_schema.py` checks `write_sedml`, the `net2sbml --sidecar` output, `write_sedml_protocol` over the repository's `.bngl` corpus, and the SED-ML in archives of each shape the writer has, with `lxml.etree.XMLSchema` against a vendored copy of the schema in `tests/data/sedml_schema`. `lxml` joins the `test` extra. It found one: a `min` or `max`, which SED-ML L1V3's MathML does not have, in an action's expression or a derived parameter said again as the model runs. Each is now written as a `piecewise`, and `read_sedml_protocol` reads a `piecewise` as BNGL's `if`, which a replay evaluates; it refused `piecewise(...)`.
