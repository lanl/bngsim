- **Two architectures sharing one codegen cache loaded each other's libraries** ([#1486](https://github.com/lanl/bngsim/issues/1486)). The cache key named the codegen version and the emitters' source but not the machine, so a native arm64 Python and an x86_64 one under Rosetta, or the x86-64 and aarch64 nodes of a cluster on one home directory, named the same model's library alike, and the second to run failed with `dlopen failed ... incompatible architecture`. The key now ends with the architecture (`43+<digest>+arm64`). `bngsim-cache info` counts an artifact that differs from this install's key in the architecture alone as `other arch`, and `prune --orphaned` leaves it to the install that can load it.
