- **bngsim's SED-ML targets named no SBML element.** Every XPath target used an `sbml:` prefix the document never declared, so the BioSimulators validator rejected the file. A `setConcentration("A()", ...)` was written as `species[@id='A()']`, where the SBML's id is `A`, so it matched nothing. Both writers now declare the prefix and resolve each species, parameter, observable and function to its id in the SBML (`sbml=`, `model=` on `write_sedml` and `write_sedml_protocol`; `net_to_omex` and the CLI pass them). An expression or `addConcentration` value becomes `computeChange` or `setValue` math.
