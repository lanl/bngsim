- **A hand-edited `.net` no longer loads clean as a different network** ([#1498](https://github.com/lanl/bngsim/issues/1498)). The reader found `begin`/`end` markers by a search of the raw line for one spelling, so `begin<TAB>reactions` opened no block and the model loaded with 0 reactions (a flat trajectory, reported as success); a trailing comment saying `end reactions` ended the block and lost every reaction from that line on; a negative species index was filtered out with the null species, so `C -> B` loaded as `0 -> B`; and a block of an unknown name was passed over. Markers are now read as BNG2.pl's `readFile` reads them: the comment off, `begin` or `end` as the first word, the name's whitespace collapsed. What BNG2.pl refuses is refused by name: an unknown block, a mismatched or missing `end`, a `begin` inside a block, a second `begin model`, a block after `end model`, and an index that is not a species index; so is a data line outside every block, which BNG2.pl only warns of. `begin model` and `end model` (either alone), actions with or without a `;`, `seed species`, the blocks BNG2.pl writes with `include_model=1`, and `actions` and `protocol` blocks load as before.
