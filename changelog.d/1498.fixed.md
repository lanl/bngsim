- **A hand-edited `.net` no longer loads clean as a different network** ([#1498](https://github.com/lanl/bngsim/issues/1498)). The reader found `begin`/`end` markers by a search of the raw line for one spelling, so `begin<TAB>reactions` opened no block and the model loaded with 0 reactions (a flat trajectory, reported as success); a trailing comment saying `end reactions` ended the block and lost every reaction from that line on; a negative species index was filtered out with the null species, so `C -> B` loaded as `0 -> B`; and a block of an unknown name was passed over. run_network and BNG2.pl read the first two as the network written and refuse the rest. Markers are now read as BNG2.pl's `readFile` reads them: the comment off, `begin` or `end` as the first word, the name's whitespace collapsed. An unknown block, a data line outside every block, another block's `end`, a `begin` inside a block, a block with no `end`, and an index that is not a species index are refused by name. `begin model`, BNG2.pl's top-level actions, `seed species` and the blocks it writes with `include_model=1` load as before.
