- **On an install with no BioNetGen, `Model.from_bngl`'s error and `capabilities()["missing"]["bngl"]` ended with advice for bngsim's own developers ([#1692](https://github.com/lanl/bngsim/issues/1692)).** The closing sentence about the `parity_checks/` suite and `uv sync --extra dev --group parity` meant nothing to a user of the wheel. Both messages now end at the fix that applies to them: `pip install 'bngsim[bngl]'`, or point `$BNGPATH` at a BioNetGen folder. Contributors still get the `--group parity` advice: from the `parity_checks/` entrypoints when they abort, and from the test suites' skip summaries.
