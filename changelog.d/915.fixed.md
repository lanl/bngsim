- **An event assignment whose value steps in time at its own fire instant gets
  the right sensitivity, or a refusal.** `u := piecewise(5, time >= T0 + 1, 0)`
  assigned by an event at `time >= T0 + 1` is 5 whatever `T0` is. The jump took
  the value's derivative in the parameter and in the fire time separately, each
  a difference across the step, and they cancelled only when the two steps
  happened to be the same size: dB/dT0 came back as 3.3e6 for 0, with no
  warning. A value that reads the time is now differenced along the column's
  own direction, the parameter and the fire time moving together. A step the
  fire time does not carry (a literal `time >= 2.3` read by an event that moves
  across it, or a step another parameter moves across the event) is a kink, and
  the run is refused.
