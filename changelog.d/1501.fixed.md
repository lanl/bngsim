- **Sample times at, or within roundoff of, the start of a plain ODE run were refused ([#1501](https://github.com/lanl/bngsim/issues/1501)).** Replicate measurements at t = 0, `sample_times=[0, 0, 0, 5, 5, 5, 10, 10, 10]`, failed with `CV_TOO_CLOSE` on every ODE run without events, roots or sensitivities, as did a sample a double after the start, `[0, 5e-324, 1]` (`CV_ILL_INPUT`) and a uniform grid whose first step rounds onto `t_start`. The same grid ran on a model with an event. The default path now takes such an output as reached, recording the start state at the time asked for, as the event-capable loop does; every other row is the bits it was. A refusal of the time grid that remains (a sensitivity run, one double after the start) is no longer routed through the Jacobian retry, whose warning blamed a discontinuous rate law.
