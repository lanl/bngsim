- **A condition reached through an SBML function definition is registered once
  (issue #1082).** A formal bound to a call such as `time()` or `sin(time())` was
  spliced into the function body as `(time())`, while the same comparison written
  directly read `time()`. The condition scans match by text, so each edge was
  registered twice: `near(time, 2.5, 0.005)` beside `abs(time - 2.5) < 0.005`
  gave four entries in `time_discontinuity_conditions()` instead of two, and as
  many roots. Results were and are unchanged. A call is now spliced bare, as a
  name or a parenthesised group already was; it binds tighter than any operator.
