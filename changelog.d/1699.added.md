- **An agent guide in the wheel, and an `llms.txt` index of the documentation ([#1699](https://github.com/lanl/bngsim/issues/1699)).** `bngsim.agent_guide()` returns one page for the installed version, with no network: the calls, eight rules that otherwise give wrong answers, what a refusal means, what each feature needs, a translation table from libRoadRunner, Tellurium, AMICI, COPASI, BioNetGen and PySB (generated from the table the wrong-name errors read), how to check a result and how to report a bug. `python -m bngsim guide` prints it and `python -m bngsim skill` prints it as a `SKILL.md` file. The documentation includes the same file, and its build writes `llms.txt`, `llms-full.txt` and each page's Markdown, which Read the Docs serves at `bngsim.readthedocs.io/llms.txt`. A test runs every block of the guide and holds it to a 32,000-character budget. The module docstring, which pointed to a README the wheel does not hold, now points to the guide.
