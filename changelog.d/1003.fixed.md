- **A forward-sensitivity column that has no frame for a singular edge its parameter moves is refused** (#1003). A window that closes or opens as a power, `(1 - s)^(a-1)` with `1 < a < 2`, has its columns carried in a frame that moves with the edge, at a shift read off the power's base. For a parameter in the denominator or the scale of the edge's time (`wb` in an onset `on/(wc + wb - wa)`, `dw` in a width `dd/dw`), or under a base that is not linear in the time, that shift is not a number, there was no case, and the column was integrated plain: dX/d(wb) 12% off at `a = 1.1`, or a run that ended in "CVODE made no progress". Such a run now raises, naming the parameter. So does a column that needed a case in a model whose cases were not worked out (the derivation budget ran out, or the model is given none): those were plain too. A parameter in the base that does not move its zero keeps its column.
