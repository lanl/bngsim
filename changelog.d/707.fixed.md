- **A derived parameter's sensitivity column is no longer exactly zero on the difference-quotient path** ([#707](https://github.com/lanl/bngsim/issues/707)). With `kd = 2*k0` and a rate law the analytic sensitivity right-hand side declines (`kd*abs(Atot)`), CVODES takes each column by moving one parameter and reading the right-hand side. bngsim mirrored the moved value into the model and then re-derived every derived parameter, so a moved `kd` went back to `2*k0` before the right-hand side was read: the column for `kd` came back all zeros, with no warning, from `Simulator.run` and from `compute_all_sensitivities(params=["kd"])`, on `.net`, BNGL and SBML input. The moved parameter is held now, and what reads it is re-derived from it. Columns for primary parameters, and every column on the analytic path, are unchanged.
