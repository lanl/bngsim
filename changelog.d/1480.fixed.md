- **`Model.from_bngl` and `bngsim.run_bngl` capped a file's network with the
  limits of a `generate_network` after its first run (issue #1480).** Such a
  file is loaded as its first run starts, and BNG2.pl generates that run's
  network with its defaults, but the loader forwarded the file's last
  `generate_network`: `simulate(...)` followed by
  `generate_network({max_iter=>3})` loaded a network cut off at 3 iterations.
  The limits now come from the first `generate_network`, and only when no run
  comes before it.
