- **The "New test files run somewhere" check read a pytest command that names no path as running nothing, though pytest then runs `testpaths` (`python/tests`).** Such a workflow was skipped, and a new file only it ran was reported as run by no check. A command with no path now runs the whole suite; one with `--version`, `--help`, `--collect-only`, `--fixtures` or `--markers` runs none. A redirect's file descriptor (`2>&1`) is not read as a path, and a step whose command is `pytest` alone is read. No workflow runs pytest that way today, and the six that run it read the same as before.
