- **`net_to_omex`'s SED-ML left a value the SBML computes by an `initialAssignment` where the simulator computed it on loading, when a parameter it reads was set as the model ran ([#1733](https://github.com/lanl/bngsim/issues/1733)).** A scan of `k1` beside a derived `k2 = k1*3` gave A(1) = 75.46, 50.12, 37.52 on libRoadRunner for BNG2.pl's 75.46, 75.00, 75.00, and a dose scan of `A0`, with the seed `A() A0`, was flat at 56.77. Each such `setValue` is now followed by one of what the assignment computes, and a seed follows its parameter until a run; so does a species set to an expression, `setConcentration("A()","A0*2")`. The changes before a run are written in the order the actions made them, each after what it reads: `setParameter("kr","k2*2")` after `setParameter("k1",5)` ran `kr = 6` for 30, and an `addConcentration` to a seed added to the amount the SBML holds. The `sedml_lossy` note goes, except for an assignment SED-ML math cannot say (an SBML function, or time). `read_sedml_protocol`, given the SBML, reads these `setValue`s beside a scan as the model's seed or expression, not as a loss, and in a chain as part of the first run it replays, not a second run.
