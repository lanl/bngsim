- **`net_to_omex`'s SED-ML left a value the SBML computes by an `initialAssignment` where the simulator computed it on loading, when a parameter it reads was set as the model ran ([#1733](https://github.com/lanl/bngsim/issues/1733)).** A scan of `k1` beside a derived `k2 = k1*3` gave A(1) = 75.46, 50.12, 37.52 on libRoadRunner for BNG2.pl's 75.46, 75.00, 75.00, and a dose scan of `A0`, with the seed `A() A0`, was flat at 56.77 for 28.38, 56.77, 85.15. The same held for a `setParameter` between runs, and, with no warning, for one before a run that a later run continues. Each such `setValue` is now followed by a `setValue` of what the assignment computes, with its own math, and a seed follows its parameter until a run, as BNG2.pl's does. The `sedml_lossy` note goes, except for an assignment SED-ML math cannot say (one that calls an SBML function or reads time). `read_sedml_protocol`, given the SBML, reads a seed's `setValue` beside a scan as the model's own seed, not as a loss.
