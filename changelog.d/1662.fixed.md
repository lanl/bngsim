- **`read_sedml_protocol` read a foreign SED-ML document as one run per time course, chained, with every model change dropped and no task read ([#1662](https://github.com/lanl/bngsim/issues/1662)).** A task whose model set k2 = 0 ran the unchanged model (A(1) = 56.77 for 36.79); two independent tasks ran the second from where the first ended (50.92 for 56.77); two tasks on one time course were one run. On BioModels' SED-ML for BIOMD0000000010 the second task gave MAPK_PP(12000) = 79.8 for 92.7, with no warning. The document is now read by task: each task runs its model from its initial state, with the model's `changeAttribute` and `computeChange` changes (a species' value, a parameter's, a kinetic law's local as `_lp_<reaction>_<id>`, an addition) as the steps before it; a `repeatedTask` sweeps (a constant `setValue` beside it as a step) or chains its subtasks on one state; the state is reset between tasks; a chain that repeats the start of a longer one is read once. A change the replay cannot apply is said and recorded in `spec.lossy`, which `run_protocol` refuses unless `allow_lossy`. A species' `initialAmount` needs `sbml=` for its compartment's size, else it is lossy too.
