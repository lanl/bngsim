- **`steady_state(sensitivity_params=...)` refuses `dY_ss/dp` at a state a run does not stay at** ([#995](https://github.com/lanl/bngsim/issues/995)). An integration stops at the first state under `tol`, which a run may be passing (BIOMD0000000407 is returned as it starts), and a root can be one the system leaves: the middle root of a bistable switch, the fixed point inside a limit cycle, which `method="newton"` finds. `-J⁻¹·∂f/∂p` there is how the root moves: dX*/da = 1 came back for `X' = -k·X·(X - a)·(X - 1)` started at a. A run is now taken on for `max_time` from a millionth beside the returned state, with `max_steps` steps, and `SimulationError` is raised where a column solved again at its end moves by more than 1%, or the run fails or stops short of `max_time`. It is raised too where an eigenvalue of the system has a real part above `0.01/max_time` (up to 512 unknowns), for a state a run of that length is too short to be seen leaving. New on the result: `sens_root_hold_shift`, `sens_root_hold_drift`, `sens_root_hold_steps`, `sens_root_hold_time`, `sens_root_growth_rate`, `sens_root_spectral_radius`.
