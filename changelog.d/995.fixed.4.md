- **`steady_state(sensitivity_params=...)` refuses `dY_ss/dp` at a state the system does not rest at** ([#995](https://github.com/lanl/bngsim/issues/995)). A model started on a root it leaves, the middle root of a bistable switch or the fixed point inside a limit cycle, is returned there, and `-J⁻¹·∂f/∂p` is how that root moves, not where a run ends: dX*/da = 1 came back for `X' = -k·X·(X - a)·(X - 1)` started at a. `SimulationError` is raised where the system the columns are solved on has an eigenvalue right of zero (up to 512 unknowns) or a determinant of the sign an odd number of them gives it. New on the result: `sens_root_stability`, `sens_root_growth_rate`.
