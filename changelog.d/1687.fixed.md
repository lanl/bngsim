- **`run_protocol` skipped a set before the first run of an actions block with no `generate_network`, as already in the network ([#1687](https://github.com/lanl/bngsim/issues/1687)).** On a `.net` loaded on its own, `setConcentration("A()",50)` then a run gave A(1) = 36.79 for 18.39; that is the actions file `omex_to_net` writes. `parse_bngl_protocol` now generates the network at the first run only where the text holds a model; an actions block alone runs every action on the network it is given, or from a `readFile` of a `.net`. `omex_to_net`'s actions file holds the actions from the protocol's generation point, with any save before it made again, so an `addConcentration` before generation is not added twice.
