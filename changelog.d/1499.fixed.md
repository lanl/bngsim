- **`write_sbml` flattened a comparison of a comparison, even BNG2.pl's bracketed `if(((0<x)<1),k,0)` ([#1499](https://github.com/lanl/bngsim/issues/1499)).** ExprTk, BNG2.pl and run_network read `(0<x)<1` as a comparison of the truth value of `0<x`; libsbml's `parseL3Formula` dropped the brackets and wrote `0 < x < 1`, and turned the "not" idiom `(x>1)==0` into `(x>1) && (1 == 0)`, so the written SBML gave A(1) = 3.679 for 10 and B(1) = 10 for 3.679, and `net_to_sbml`'s gate passed a band model that stopped at 20 for 30. The writer now brackets every relational chain as ExprTk groups it (`1<x<2`, `a==b<1`, ...) and writes a truth value that a relational compares, a relational or a logical, as `piecewise(1, cond, 0)`, which libsbml keeps and which is well-typed SBML. Function assignment rules and derived-parameter initialAssignments both go through it.
