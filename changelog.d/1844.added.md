- **`Model.describe()` says whether a steady state can be solved for ([#1844](https://github.com/lanl/bngsim/issues/1844)).** `methods["steady_state"]` is `refused` for a model with an event, a compartment size that jumps, a state the time reaches, one the ODE Simulator refuses, or one with no species, listing every reason with the message `steady_state()` raises for the first; `steady_state()` and `steady_state_batch()` now raise from the same check. Otherwise `ok`, with a note that the call still checks the model's conservation laws and that a solve can fail to converge.
