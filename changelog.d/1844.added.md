- **`Model.describe()` says whether a steady state can be solved for ([#1844](https://github.com/lanl/bngsim/issues/1844)).** `methods["steady_state"]` is `refused` for a model with an event, a compartment size that jumps, or a state the time reaches, with the message `steady_state()` raises, read from the one check both now call; otherwise `ok`, with a note that the call still checks the model's conservation laws and that a solve can fail to converge.
