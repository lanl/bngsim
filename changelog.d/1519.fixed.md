- **An event on `time == c`, where an event writes c, fired only where an output sample or a point of the SSA's trigger-probe lattice landed on the instant ([#1519](https://github.com/lanl/bngsim/issues/1519)).** A dose counter `at (time == c && c < 91): c = c + 1` from c = 0.5 gave all 10 doses over (0, 10) at `n_points=101` and none at 100 or 102, with nothing said; BIOMD0000000620 (Palmer2014) lost every anakinra dose that way. The instants are now placed stretch by stretch between the executions of the events that write c, the trigger's own included, in the ODE and stochastic engines, where those events fire at a fixed time or on such an instant and set values known before the run. That covers a side read through an assignment rule, a delayed trigger, `!=`, and a species held by `c' = 0`. Where the instants cannot be placed (a state trigger writes c, two writers at one instant, more than 512 executions in a run) the run is refused by name.
