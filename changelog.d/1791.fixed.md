- **`sbml_to_net` wrote a `.net` that BioNetGen's `run_network` refused, where an assignment rule read one listed after it ([#1791](https://github.com/lanl/bngsim/issues/1791)).** The functions block followed the SBML's rule order, and `run_network` reads it top to bottom: `y := 3*x` before `x := k/2` stopped it with "Could not find variable 'x'", and BIOMD0000000268 has five such rules. bngsim sorts functions when it loads a `.net`, so its own reload, and the converter's validate gate, read the file fine. Each function is now written after the functions it reads; a block already in order is written as it was. Of 1323 BioModels, 77 had such a read and 1214 come out byte-identical. Functions that read each other in a cycle have no order: they are written after the rest, with a `ConversionWarning`. The same holds for `bngsim.convert.write_net`, which `sbml_to_net` writes through.
