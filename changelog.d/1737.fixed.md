- **A SED-ML change that set a species from a parameter followed that parameter, so a scan of it moved the species, with no warning ([#1737](https://github.com/lanl/bngsim/issues/1737)).** SED-ML evaluates a `computeChange`'s or `setValue`'s math once, where it applies, as `read_sedml_protocol` already read a parameter's (#1682), but a species' was kept as a live expression until the next run. A model change `A = A0*2` and a resetting scan of A0 over 10, 20, 30 replayed A(1) = 11.35, 22.71, 34.06 where the document gives 113.53 at each point. The change is now read as evaluated once, and `run_protocol` applies it so. A `setValue` in the sweep that reads the sweep's own range still follows it (#1733), and a BNGL block written from the protocol (`write_bngl_protocol`, or `write_bngl` with a `protocol`) now warns where BNG2.pl runs it from another amount: where a run starts from the `setConcentration`'s expression, which BNG2.pl keeps until a run and a reset to a save of it brings back (a resetting scan's, at each point), after a parameter it reads was changed or scanned, and where an `addConcentration` finds the expression and adds to the declared amount.
