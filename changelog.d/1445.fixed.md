- **A sensitivity run no longer refuses a state that leaves a rate-law equality at once after a clock stop no requested column moves** ([#1445](https://github.com/lanl/bngsim/issues/1445)). Since #1411 a leaving right after a restart was let through only at the run's start or after an event at a fixed time: `if(Bobs==0, kb, 0)` with B made from `time() > t3` was refused at t3, where dY/d[kp, kb] = [0, t3] exactly. A crossing stop, and a switch time no requested column moves, now count as fixed restarts too. With t3 requested the run is still refused, since the #48 jump at t3 reads Y's flow with B still on the surface (dY/dt3 would be 0 for 1).
