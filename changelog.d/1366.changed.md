- **`Model.from_bngl` warns when the source's first run starts somewhere else** ([#1366](https://github.com/lanl/bngsim/issues/1366)). The actions after a BNGL file's `generate_network` are dropped as the author's experiment, as before. When some of them set a parameter or a concentration that the first `simulate` or `parameter_scan` starts from, a `ConversionWarning` now names them. It names only those that change what the loaded model holds: a `setConcentration` to the species' own amount, or a `saveConcentrations()` / `resetConcentrations()` pair, is not named. `protocol=True` returns the actions instead, without the warning. The loading docs now say which actions before `generate_network` are applied, and the benchmark README says that suites run the network from its seed state, not the published protocol.
