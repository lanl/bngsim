- **A sensitivity run on a clone no longer repeats the sympy analysis of the model's functions** ([#979](https://github.com/lanl/bngsim/issues/979)). The analysis behind the output sensitivities of global functions is memoized on each `Model`, and a clone took a copy of the memo: a clone of a model that had never been analyzed started with nothing, and so did the next. A fitting loop that clones one base model for every evaluation paid it each time, 2.2 s a run for 300 functions over 32 parameters where the integration takes milliseconds. A model and its clones now also hold one memo together, which any of them fills. `Model.clone()` parsed every function with a logarithm and no conditional to see whether it needed the zero-base guard, 0.25 s a clone for the same model; the answer is memoized by the function's text. A model that is loaded, not cloned, still makes its analysis once.
