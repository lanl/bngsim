- **A sensitivity run on a clone no longer repeats the sympy analysis of the model's functions** ([#979](https://github.com/lanl/bngsim/issues/979)). The analysis behind the output sensitivities of global functions was memoized in a slot of each `Model`, copied when the model was cloned: a clone of a model that had never been analyzed started with nothing, and so did the next. A fitting loop that clones one base model for every evaluation paid it each time, 2.2 s a run for 300 functions over 32 parameters where the integration takes milliseconds. The memo is now one that a model and all of its clones hold, keyed by what can differ between them (which derived parameters are attached, the table functions, the derivation budget). `Model.clone()` also parsed every function with a logarithm to see whether it needed the zero-base guard, 0.25 s a clone for the same model; that is memoized by the function's text. The first sensitivity run of a process still makes the analysis once.
