- **`compute_all_sensitivities(n_points=0)` no longer kills the interpreter** ([#1523](https://github.com/lanl/bngsim/issues/1523)). It checked neither `t_span` nor `n_points`, and with a time switch inside the span an empty output grid reached `CvodeSimulator::run`, which read the ends of it through a null pointer (SIGSEGV). Without a switch it raised a `SimulationError` that blamed tolerances, `n_points=1` returned a one-row result, and `t_span=(10, 0)` returned three rows at `t = 10` with zero sensitivities. It now makes `run()`'s checks and raises the same `ValueError`; that covers the JAX bridge's derivative rule too, which calls it. Every ODE, SSA and NFsim run also refuses an empty grid at entry.
