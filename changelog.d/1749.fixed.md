- **An ODE sensitivity run from a state an SSA or PSA run left seeded dx(0)/dθ = 0 with no error, where one from a state an ODE run left is refused ([#1749](https://github.com/lanl/bngsim/issues/1749)).** Only the CVODE write-backs set GH #210's carried-over mark. A stochastic run now sets it too, and the mark issue #1528 reads for `sensitivity_ic`, and drops any seed an earlier sensitivity run left, which `carry_sensitivities=True` would otherwise have read for a state the stochastic run had moved on from. So each such run is now refused, as after an ODE run. The refusal says how to take the state as fixed data, with dx(0)/dθ = 0: `set_state()` the run's last result row after a `reset()` to a baseline no run advanced, or on a fresh `Model` once an advanced state has been saved as the baseline; the `carry_sensitivities=True` refusal names the stochastic run that dropped the seed. As after an ODE run, `set_param()` of an initial-condition parameter no longer re-doses a species in the state an SSA or PSA run left, and `steady_state(sensitivity_params=...)` of one that sets a conservation law's total is refused there.
