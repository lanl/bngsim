- **A `Result` can make its run again: `Result.rerun()` ([#1703](https://github.com/lanl/bngsim/issues/1703)).** It builds the model from the recorded file, once the file's sha256 still matches, or from the text a string load kept; gives it the parameters, start state and event state the run started from; and runs at the method, seed, sample times, tolerances as applied, Jacobian, linear solver and right-hand side the record names, so an ODE run comes back bit for bit, and a stochastic one too on the same build. The model the run used is neither read nor changed. `rerun(rtol=1e-10)` and the like change one setting and keep the rest, and the new record's `run.rerun_of` says which record was repeated and what changed. Where the record cannot promise the same run (a stack of runs, a network-free run, stop conditions, carried sensitivities, a model edited after its load, a file changed on disk) it refuses with a `rerun.*` code. The record gains `run.start_carry`, `run.declared_ic_sensitivity`, `run.rerun_of` and `model.edits`.
