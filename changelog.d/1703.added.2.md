- **A `Result` can make its run again: `Result.rerun()` ([#1703](https://github.com/lanl/bngsim/issues/1703)).** It builds the model from the recorded file, once its sha256 still matches, or from the text a string load kept, gives it the parameters, start state and event state the run started from, and runs at the recorded method, seed, times, tolerances as applied, Jacobian, linear solver and right-hand side: an ODE run comes back bit for bit, a stochastic one too on the same build. The model the run used is neither read nor changed. `rerun(rtol=1e-10)` changes one setting and keeps the rest, and the new record's `run.rerun_of` says what was repeated and changed. Where the record cannot promise the same run (a stack, a network-free run, stop conditions, carried sensitivities, an edited model, a file or table data changed on disk) it refuses with a `rerun.*` code. A string-loaded model keeps its text, which `save()` writes into the file. The record gains keys for what a rerun reads.
