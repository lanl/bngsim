- **A sensitivity column that moves a window edge that is a singular power is refused in a model with an event** ([#958](https://github.com/lanl/bngsim/issues/958)). A window `k1*s*(1-s)^(a-1)` closes as a power, and for 1 < a < 2 the column of a parameter that moves its edge is integrated in a frame that moves with the edge. A model with any event keeps every column plain, so the same column integrated a forcing that is unbounded at the edge: dX/dD came back 1.0789 for 1.0830 beside an event that assigns a parameter nothing reads, at any tolerance, and a window that opens as a power ended in `CV_FIRST_SRHSFUNC_ERR`. Such a run is now refused, before it starts for the switch times it has and at the crossing for one found as a root, with a message that names the parameter and the crossing. Whether a power is singular is asked at the run's own values: at a = 3 nothing is unbounded and the run goes through as before, as does a column that does not move the window.
