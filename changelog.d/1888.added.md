- **`Result.rerun(linear_solver=...)` and `check("linear_solver")` ([#1888](https://github.com/lanl/bngsim/issues/1888)).** `rerun()` takes an ODE run's linear solver, `"dense"`, `"klu"` or `"auto"`, through the Simulator's `force_dense_linear_solver` and `force_sparse_linear_solver`, so a run that fails on KLU can be made again dense with one call. `check("all")` adds `linear_solver`: the run on the other solver (dense for a KLU run, KLU for a dense one), judged species by species like the other paths, or `skip` with the reason where KLU cannot run the model (a build without KLU, no sparse Jacobian pattern, a JAX Jacobian).
