- **A sensitivity run reads its columns at the state its value RHS reads f at** ([#1298](https://github.com/lanl/bngsim/issues/1298)). Where the value RHS is non-finite at a state with a species a hair below 0, it reads f at the clamped state (#135), or at the reading near 0 after it (#1340), and the run integrates that. The sensitivity RHS refused those states: on MODEL2001200002, a simultaneous run on the closed-form Jacobian failed at t = 22, and under `jacobian="auto"` it was taken again on the difference quotient (GH #176), at 4.9 times the plain run's steps. The sensitivity RHS now reads its columns where the value RHS read f: that run takes 1.06 times the plain run's steps, with no second attempt. It does so only where each species read at 0 is below 0 by the run's own error: not driven further down, at most 100 of its error units deep, and with its own entry of the column within tolerance. Elsewhere the columns read there were wrong, with no error, and the state is refused as before. `BNGSIM_SENS_AT_VALUE_STATE=0` turns the reading off.
