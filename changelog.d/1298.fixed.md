- **A sensitivity run reads its columns at the state its value RHS reads f at** ([#1298](https://github.com/lanl/bngsim/issues/1298)). Where the value RHS is non-finite at a state with a species a hair below 0, it reads f at the clamped state (#135), or at the reading near 0 after it (#1340), and the run integrates that. The sensitivity RHS refused those states: on MODEL2001200002, a simultaneous run on the closed-form Jacobian failed at t = 22, and under `jacobian="auto"` it was taken again on the difference quotient (GH #176), at 4.9 times the plain run's steps. The value RHS now records where it read f, and the sensitivity RHS reads its columns there, so the run takes the plain run's path: the simultaneous run in 1.06 times its steps, with no second attempt. The staggered run, which those refusals had left at 0.19 times the plain run's steps on that model, takes 1.22 times, at the same state. Where the value RHS reads f at the state itself, a non-finite column is refused as before. `BNGSIM_SENS_AT_VALUE_STATE=0` turns the reading off.
