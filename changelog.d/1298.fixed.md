- **A sensitivity run could return a different trajectory from its plain run, and columns that were wrong, with only a warning** ([#1298](https://github.com/lanl/bngsim/issues/1298)). On MODEL2001200002 the state was 2.6e-3 of its peak off the plain run's, and the columns were 0.28 to 1.0 of their peak off a central difference of plain runs. A species the run had taken a hair below zero, where `(L/T)^1.36` is NaN, is integrated at the clamped state (#135), but the sensitivity RHS refused that state once it was further below zero than atol. The run then gave up and was rerun with the finite-difference Jacobian. Where the value RHS is non-finite at the state, the sensitivity RHS is now evaluated at the same clamped state, so the columns are those of the flow the run integrates. Where the value RHS is finite there, a NaN in a column is still refused, as before. Of 1,190 BioModels run with three sensitivity columns each, two other models changed, by under 2e-6 of a column's peak.
