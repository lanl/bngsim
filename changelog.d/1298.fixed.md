- **A sensitivity run reads its columns at the state its value RHS reads f at** ([#1298](https://github.com/lanl/bngsim/issues/1298)). Where the value RHS is non-finite at a state with a species a hair below 0, it reads f at the clamped state (#135), or at the reading near 0 after it (#1340), and the run integrates that. The sensitivity RHS refused those states: on MODEL2001200002, a simultaneous run on the closed-form Jacobian failed at t = 22, and under `jacobian="auto"` it was taken again on the difference quotient (GH #176), at 4.9 times the plain run's steps. The value RHS now records where it read f, and the sensitivity RHS reads its columns there: that run takes 1.06 times the plain run's steps, with no second attempt. A state with a species the flow there drives further below 0, or far below it, is still refused: J there keeps a slope in it the flow does not have, and its columns were wrong. `BNGSIM_SENS_AT_VALUE_STATE=0` turns the reading off.
