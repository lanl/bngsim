- **A run with sensitivity columns recorded an event's row before the event, where the same run without them recorded it after** ([#1182](https://github.com/lanl/bngsim/issues/1182)). Since #1133 a plain run fires an event whose trigger on the state crosses within CVODE's root tolerance after an output, and records that row after it. `species S = 3; q = 0; k = 1; q' = k; at (q >= 2.5): S = 1` on [0, 1, 2, 2.5, 3] gave [S] = 1 at 2.5 without sensitivities and 3 with `sensitivity_params=["k"]`. A sensitivity run now fires there too, takes the row as the crossing, and jumps its columns with ∂t*/∂θ read from the trigger's flow, as at a located crossing. With `S' = 1` and `S = S/2`, dS/dk at the row is 1.25, the closed form.
