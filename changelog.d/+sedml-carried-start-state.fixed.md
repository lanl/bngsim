- **A protocol's SED-ML started every experiment from the model's initial state, where BNG2.pl starts it from the state the steps before it left, with nothing said.** In an equilibrate-then-stimulate protocol such as `egfr_path.bngl`, a standards tool ran the stimulation from the unequilibrated model. `write_sedml_protocol` (behind `net_to_omex(bngl=...)` and `bngsim-net2sbml --sidecar`) now warns, naming each such experiment and why: the end of an earlier run, an `addConcentration`, a value only the model can read, a parameter a scan left, or a saved state a reset restored. The bngsim annotation keeps the protocol exact.
