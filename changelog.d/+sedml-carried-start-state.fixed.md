- **A protocol's SED-ML ran every experiment from the model's initial state, where BNG2.pl runs it from the state the steps before it left.** In an equilibrate-then-stimulate protocol such as `egfr_path.bngl`, the stimulation ran on the unequilibrated model. `write_sedml_protocol` (behind `net_to_omex(bngl=...)` and `bngsim-net2sbml --sidecar`) now writes such a run as a `repeatedTask` that replays the runs before it as ordered subtasks on one model state, with the actions between them as `setValue` changes. Run that way, `egfr_path`'s stimulation matches BNG2.pl's replay to 4e-10. A bifurcate is its sweep up and back down. A scan with `reset_conc=>1` from a carried state still warns.
