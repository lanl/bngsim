- **`RuleMonkeySession.initialize(seed, t_start=0.0)` and `bngsim.RuleMonkeyWarning`** (#1022). `t_start` puts the initial state at that time on the model's clock, so a session can start where a `run(t_span=(t_start, ...))` does; `initialize(seed, t_start=5)` then `simulate(5, 7, ...)` is that run draw for draw. `RuleMonkeyWarning` is raised when a `method="rm"` simulator or a session is built, once for each thing RuleMonkey flags in the XML without refusing it: a rule whose products can never form (it never fires), a keyword it ignores (`priority`, `MoveConnected`), or a construct it reads differently from BioNetGen's network (`TotalRate`, `reactant_N()` outside it, a Michaelis-Menten pattern matching several species). bngsim used to drop these.
