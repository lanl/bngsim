- **An ODE run over a span near the largest double hung, or returned NaN rows,
  with no error (issue #1838).** CVODE's step overflowed before the run ended:
  `(0, 7e307)` never returned and `timeout=5` did not stop it, and
  `(1e308, 1.7e308)` of a model that reads the clock came back as
  `[1, 0, nan, nan, nan]`. An ODE run with a time 2^512 (about 1.34e154) or
  more from 0, or that long, is now refused with `UsageError` before it
  starts: measure time in a larger unit. And `timeout=` is now read inside the
  solver too, every 256 right-hand-side evaluations, so a run that spends its
  budget between two output points raises `SimulationTimeout`.
