- **An ODE run over a span near the largest double hung, or returned NaN rows,
  with no error (issue #1838).** CVODE's step overflowed before the run ended:
  `(0, 7e307)` never returned and `timeout=5` did not stop it, and
  `(1e308, 1.7e308)` of a model that reads the clock came back as
  `[1, 0, nan, nan, nan]`. Such a run now raises `UsageError` at the step that
  overflows, as does one that failed there with a CVODE error, and a run whose
  length is itself past the largest double is refused before it starts:
  measure time in a larger unit. Every run that returned before returns the
  same rows. And `timeout=` is now read inside the solver too, every 256
  right-hand-side evaluations, so a run that spends its budget between two
  output points raises `SimulationTimeout`.
