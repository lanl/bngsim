- **SSA and PSA stored an event's concentration assignment over the load-time size in a compartment an assignment rule sizes ([#1659](https://github.com/lanl/bngsim/issues/1659)).** In `c := 1 + time`, `at (time >= 2): S = 50` stored an amount of 50 where the size was 3, and `[S](3)` read 12.5 for 37.5. The event now stores the concentration times the size the rule gives at the event, as it already did for an event-resized or rate-rule compartment.
