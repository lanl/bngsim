- **SSA and PSA round only molecule counts (issue #718).** An SBML parameter or
  compartment that an event assigns, and a rate-rule target, hold continuous
  values, but each run and `run_until` leg rounded them to whole numbers: a
  rate constant of 0.5 ran as 1 and 0.4 as 0, a volume of 0.4 as 0, and a
  rate-rule variable restarted every leg from a whole number, silently. They
  now keep their values, and a leg hands the next one the rate-rule values it
  reported at its end. A fractional molecule count is still rounded, as
  `run_network` does. Each run that rounds one now raises the new
  `SsaRoundingWarning` and counts it in `ssa_diagnostics`.
