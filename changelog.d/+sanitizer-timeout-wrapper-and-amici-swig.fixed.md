- **Two nightly checks failed on their own test setup, not on bngsim.** The sanitizer job stretches each run's timeout through a wrapper around `Simulator.run`. A warning raised with a fixed `stacklevel` named the wrapper's frame instead of the caller's line, and `Result.rerun()` stretched an already-stretched timeout a second time: three tests failed there and nowhere else ([#1816](https://github.com/lanl/bngsim/issues/1816)). The weekly live parity run built AMICI from source with the newest swig, and AMICI then refused to compile any model against the swig `uv.lock` installs, so every AMICI sensitivity reference failed ([#1824](https://github.com/lanl/bngsim/issues/1824)). The wrapper is now skipped when frames are counted, the rerun test's timeout is one the wrapper leaves alone, and AMICI is built against `uv.lock`'s swig.
