- **The "New test files run somewhere" check read all of a workflow's pytest commands as one, and a shell glob that expands to a directory as no directory ([#1874](https://github.com/lanl/bngsim/issues/1874)).** One step's `--ignore` or `--deselect` was applied to a file another step runs, so a file run in a step of its own was warned about; each command is now read on its own, and a file counts as run when any command runs it. A glob such as `python/tests/su?` is now the directory bash expands it to, which pytest walks: the files under it count as run, and an `--ignore` below it applies to a file also named under it, which the check had counted as run. No workflow on main has either shape, and the six that run pytest read the same as before.
