- **An ODE run that starts far from t = 0 returned a wrong trajectory with no error ([#1681](https://github.com/lanl/bngsim/issues/1681)).** The integrator advances its clock by `t + h`, and far out the doubles are coarse: `A -> 0` at k = 1 over `(1e15, 1e15 + 10)` gave A(+5) = 0.00144 for 0.00674, and over `(1e17, 1e17 + 64)` A stayed at 1. A model that reads no clock (no function of `time()`, no table indexed by time, no event) is now run on the time elapsed since the end of the run nearer 0, wherever that end is at 2^20 or beyond, and reports the times asked for: it is the run from 0, to the bit. A run nearer 0 is unchanged. A failure of a moved run names its times on the run's clock and says which time to add. A model that reads the clock keeps the absolute one, as before.
