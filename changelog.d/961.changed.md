- **`steady_state()` solves a model whose only read of the time is a function nothing in the dynamics reads** ([#961](https://github.com/lanl/bngsim/issues/961)). `minutes := time/60` in BIOMD0000000739 and 951, and `parameter_1`'s pulse in BIOMD0000000498, made #710 refuse the whole model, though the state does not depend on them. The refusal now asks what the time reaches: a rate law (`NetworkModel.rate_laws_read_clock`, which does not count a `rateOf`), or a rule a species or compartment size is reported through. Where it reaches neither, the state is solved for, and each function that reads the clock (`functions_reading_clock`) is reported as NaN with a NaN sensitivity row, which `output_sensitivities` refuses by name. The early stop of `run(steady_state=True)` and `run_batch(steady_state=True)` is lifted for the same models, on the same test, and stops where the model without that function would. BIOMD0000000739's steady state matches a run to t = 1e9 at rtol 1e-12 to 3e-7; 498 and 951 report `converged=False`, as their runs still drift.
