- **`Model.from_bngl` no longer loads a later phase's state from a file without `generate_network`** ([#1366](https://github.com/lanl/bngsim/issues/1366)). BNG2.pl generates the network at such a file's first run, but the loader kept every `setParameter` and `setConcentration` in it, those between later runs included, so the model held the state of none of the runs. `kinetics_mb1n.bngl` loaded with its last phase's `Agconc` 604.8 and `const` 0, where its first run has 7.46 and 1. The actions now stop at the first run, as they stop at a `generate_network`.
