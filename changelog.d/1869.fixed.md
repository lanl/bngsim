- **The "New test files run somewhere" check read a test file named on pytest's command line as never left out by `--ignore` or `--ignore-glob`, though pytest 9 leaves it out when a directory holding it is named too ([#1869](https://github.com/lanl/bngsim/issues/1869)).** pytest 9 drops a collection argument that lies under another one, so the ignore applies to it, and the check counted such a file as run. It now walks the outermost named directory that holds a file and applies the ignores below it. A `--deselect` without `::` is read as a prefix of the node ids, as pytest reads it; an `--ignore` or `--deselect` glob after `=` leaves nothing out, quoted or not; and a literal `@@quoted:` word no longer raises.
