- **A `.net` Hill law whose exponent was moved into (0, 1) after loading failed at zero substrate ([#1636](https://github.com/lanl/bngsim/issues/1636)).** #1497's guard, which reads the law as 0 at S = 0 for 0 < h < 1, was written only where h was in (0, 1) at load, so `set_param`, a `run_batch` row, `parameter_scan` or a BNGL `setParameter` after `generate_network` that moved it there evaluated `inf*0` and the run failed with `CV_FIRST_RHSFUNC_ERR`. The guard is now written for every Hill law, and the issue's model gives BNG2.pl's S(5) = 2.796028127 on each route. An SSA or PSA run after h is moved there no longer fails on a NaN propensity at S = 0. A run, with or without sensitivities, a steady-state solve and `run_diffrax` read a condition the parameter values decide, such as the guard's `(h <= 0) or (h >= 1)` at h = 2, as that constant and root nothing for it, so a model at h >= 1 does not pay the root's cost, and runs wherever it ran, but for one case: `run_diffrax` of a model loaded with h outside (0, 1) and given an h inside it by `param_dict` is now refused, as a model loaded there already was. A model with events keeps every root.
