- **Every error BNGsim raises about a model, a run or an argument now has a code ([#1702](https://github.com/lanl/bngsim/issues/1702)).** The ones raised as built-in `ValueError`, `TypeError`, `KeyError`, `NotImplementedError` or `RuntimeError` are now BNGsim errors that are still those built-ins: `UsageError`, the new `ArgumentTypeError`, `NotFoundError`, `NotSupportedError`, `InvalidModelError` and `CodegenBuildError`, each with a `code` a program can branch on. Messages are unchanged, but for the class name a few quote of the error behind them (a failed codegen build is now `CodegenBuildError` there, not `RuntimeError`). One behavior change: every BNGsim error is a `RuntimeError`, so an `except RuntimeError` now also catches an argument error that used to be a plain `ValueError`. A CVODE failure's code now comes from the engine as data rather than from the message, and so does a missing compiler's.
