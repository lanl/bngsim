- **`Simulator(sensitivity_params=..., sensitivity_ic=...)` reported a name the model does not have only once the run had started, as a failed run (issue #1925).** The run raised `SimulationError` with the code `run.failed`, and a single name passed as a string (`sensitivity_params="k1"`) raised a raw pybind11 `TypeError`. The Simulator now refuses both when it is made. A missing name raises the error `set_param` or `set_concentration` raises for it: `ParameterError` (`param.not_found`) or `ModelError` (`species.not_found`), with its close matches. A species given as a parameter, or a parameter as a species, is pointed at the other keyword. A string, or a name that is not a string, raises `ArgumentTypeError` (`usage.wrong_type`). On the command line, each is a usage error that names the option.
