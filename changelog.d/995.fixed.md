- **`steady_state(sensitivity_params=...)` refuses `dY_ss/dp` where the steady state is not an isolated root** ([#995](https://github.com/lanl/bngsim/issues/995)). Where the steady states form a continuum, the one a run ends at depends on the path it took, and `-J⁻¹·∂f/∂p` is not its derivative: `S + I -> 2 I`, `I -> R` returned dS*/dg = 26.25 for 66.05, beside one logged warning. The solve now takes one Newton step from the state it returned and factors its system again there. It raises `SimulationError` where the determinant keeps less than 0.6 of itself (the Jacobian is singular at the steady state) or the componentwise condition number is above 1e12 (singular whatever the state). Both read the same in any units, which `min|U|/max|U|` did not: the warning it gated is gone, and so is the refusal it gated for a law across compartments of different size, which stopped isolated roots with sizes 1e5 apart. Take such columns from a time course with forward sensitivities. New on the result: `sens_root_determinant_ratio`, `sens_root_condition`.
