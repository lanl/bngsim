- **Every BNGsim error carries a stable code, its details and remedies a program can act on ([#1702](https://github.com/lanl/bngsim/issues/1702)).** A tool or an agent can branch on `e.code` instead of matching the message, which changes between releases. `e.details` says what the error is about (the name and its close matches, the path, the constructs, the solver flag), `e.remedies` lists fixes as dicts with a `kind` (such as `install_package` with its `pip install` command), `e.docs_url` points at a new error-code reference page, and `e.to_dict()` gives all of it as plain data. An error with no code of its own carries its class's generic one. A missing optional package is now `bngsim.DependencyError`, a missing file `bngsim.MissingFileError` and a missing `xml_path=` `bngsim.UsageError`; each is still the `ImportError`, `FileNotFoundError` or `ValueError` it was. Messages are unchanged.
