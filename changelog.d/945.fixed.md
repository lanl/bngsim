- **A state-dependent rate-law switch on the instant of an event is refused** ([#945](https://github.com/lanl/bngsim/issues/945)). With `piecewise(q*X, V >= 6, 0)` crossing at t = 3 and an event at `time >= tau`, tau = 3, that halves X, dW/dtau is −1.05 with the switch first and −3.15 with the event first. The crossing's time is known to the tolerances of the run and not to the last bit, so the two came as two stops, each handled as if the other were not there, and the run returned −3.15. A run with forward sensitivities now ends in an error where such a switch and an event's fire are within that of each other, read no species in common, and a requested parameter moves either. An event on the species the switch reads is on one trajectory with it and is taken in order, as before.
