- **Codegen declines a Michaelis-Menten reaction whose `kcat` or `Km` a function writes** ([#931](https://github.com/lanl/bngsim/issues/931)). The engine evaluates a function into the parameter of the same name before each right-hand side; the compiled right-hand side read the parameter as it was loaded. With `kcat() = kb` over a `kcat` of 0, `MM kcat Km` never ran: P(6) came back 0 for 18 under `codegen=True`, and in every forward-sensitivity run, which always uses the compiled right-hand side, with dP/dkb = 0 for 6 and nothing logged. Such a model is now declined: a plain run uses the interpreted engine, which was right; `codegen=True` raises with the reason; a sensitivity request raises `SensitivityUnsupportedError`. `Sat` and elementary rate laws over such a name were right and are unchanged.
