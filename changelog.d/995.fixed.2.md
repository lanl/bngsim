- **`steady_state(sensitivity_params=...)` refuses `dY_ss/dp` at a state that is not the steady state a run reaches** ([#995](https://github.com/lanl/bngsim/issues/995)). `tol` bounds the residual `||f(y)||/n`, not the distance to the root: BIOMD0000000002 was accepted 0.02% from its steady state with every column 5.9% off, and BIOMD0000000407 where it starts, which a run leaves. The columns are solved again one Newton step on, and for an integration result where the run ends when it is taken on for `max_time`; `SimulationError` is raised where one moves by more than 1% of its largest entry, each species over its own scale (`sens_species_scale`). Solve again with a smaller `tol`. It is raised too where a run of `max_time` would leave more than 1% of a column unestablished (12,500 in MODEL1607210000 for a species no run moves). The state `steady_state()` returns is unchanged. New on the result: `sens_root_column_shift`, `sens_root_hold_shift`, `sens_root_hold_drift`, `sens_root_relaxation`.
