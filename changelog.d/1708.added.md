- **A `bngsim` command, also `python -m bngsim` ([#1708](https://github.com/lanl/bngsim/issues/1708)).** `bngsim doctor` says what this install can do, what is missing and the fix for each, with the Python, the platform and the C compiler codegen would use; `bngsim examples` lists the bundled models and their files; `bngsim inspect MODEL` prints `Model.describe()`; `bngsim guide` and `bngsim skill` print the agent guide as before. The converters and the cache tool are also `bngsim convert TOOL ...` and `bngsim cache ...`, unchanged. With `--json` a command prints exactly one JSON object on standard output, and anything else written there, by Python or by C, goes to standard error; an error is the `BngsimError.to_dict()` object on standard error. Exit codes are distinct: 0 success, 1 error, 2 usage error, 3 refusal, and 4 and 5 kept for a failed run and a timeout. `run` and `check` are to come.
