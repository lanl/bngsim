- **A compartment resize and an event assignment to a species in it now
  compose (issues #936, #741).**
  - **Same-instant resize undid an assignment (ODE).** A resize rescales each
    contained species to conserve its amount. That rescale read the state from
    before the event batch, so when an earlier event of the same instant had
    assigned the species, the resize undid the assignment ([Y] = 0.5 where 1 is
    right). It now reads the state when the resize executes. Its forward
    sensitivity is taken there too, and now matches finite differences.
  - **Delayed resize with its own assignment (ODE).** A delayed event that
    resizes a compartment and assigns a species in it applied the species'
    value at the apply time, not the value frozen at the trigger.
  - **SSA/PSA writes.** Under SSA/PSA, an event assigning a concentration to a
    species in a rate-rule or event-resized compartment stored c·V_static
    molecules instead of c·V_live: half the amount after a resize to twice the
    size. It now stores c·V_live, with V_live as it stands when the event
    executes.
