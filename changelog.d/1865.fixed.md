- **`run_protocol` let a held derived parameter follow a write again where it read another held parameter ([#1865](https://github.com/lanl/bngsim/issues/1865)).** Since #1738, a derived parameter that a `setParameter` sets to the number its expression gives is held at that number through later writes. With `k2 k1*0.5` and `k3 k2/k1` both set so, `setParameter("k1",3)` moved k2, which was written back, and that write moved k3 to 0.5/3, which was not: Ctot(0.5) was 2.6008 where BNG2.pl gives 7.4306. The hold now repeats until no held parameter has moved.
