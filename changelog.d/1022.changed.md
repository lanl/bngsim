- **Re-vendored RuleMonkey 3.10.1 (`87628b3`) → 3.11.0 (`f11c251`), and `method="rm"` now runs on absolute model time** (#1022). `run(t_span=(5, 7))` starts from the initial state with the clock at 5, so a rate law that reads `time()` reads 5 to 7, as `ode` and `ssa` do. Before, the run was shifted to elapsed time and such a model was refused. A model that does not read the clock gives the same counts as before, to within one molecule at a sample time. `method="nf"` stays on elapsed time, as BNG2.pl's `simulate_nf`; the two differ only through a table function indexed by time. A `RuleMonkeySession` segment that starts at `current_time` runs on the clock. One that starts elsewhere (a second `simulate(0, 10, ...)` on a session at 10) is still run as elapsed time under the labels asked for when the model does not read the clock, and is refused with `SimulationError` when it does. A session cut into several `simulate()` calls no longer repeats one uninterrupted run draw for draw; it has the same statistics.
