- **`steady_state()` could report `converged=True` at a state a run leaves,
  when the `atol` passed was coarser than the whole model (issue #1895).**
  BIOMD0000000609, every species below 1.4e-13, asked at its SED-ML file's
  `atol=1e-9`, came back converged at a root with two species near -1.5e-14,
  from which a run diverges. A scalar `atol` is still taken as given for the
  march, but the run test's run is now integrated no coarser than `rtol`
  times the largest species the solve starts with, so such a state is
  refused. The default `atol` is never that coarse, and its results are
  unchanged. `steady_state_batch()` shares the test. To solve such a model,
  leave `atol` unset or pass one at its scale.
