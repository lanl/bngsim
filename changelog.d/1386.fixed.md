- **The nightly AMICI sensitivity leg compiled BIOMD0000000457 twice on some nights** ([#1386](https://github.com/lanl/bngsim/issues/1386)). Jobs ran method-major so that a model's second corrector method would load the code its first had built. But a compile of 150-220 s outlasted the short jobs dispatched after it, so the second started early and compiled again alongside, and the doubled codegen time tripped the wall alert (x2.17 on PR #1303's run). The parity scheduler takes a `depends_on`, and the AMICI runner uses it to start a model's later methods only once its first has finished. Other workers keep taking ready jobs meanwhile.
