- **SSA and PSA computed observables and expressions on the stored count over the load-time size in a compartment whose size moves ([#1464](https://github.com/lanl/bngsim/issues/1464)).** After an event resized `c` from 2 to 4, `B := 2*X` reported 64 for 32, and every observable or expression that read `X` read it at twice its concentration; the same under a rate rule, and in a compartment an assignment rule sizes (`c := 1 + time`), where `p := 2*S` and the observable `S` never moved. The rows' observables and expressions now read such a species at its count over the compartment's live size, as the ODE run reads it. The run itself still goes on from the stored count.
