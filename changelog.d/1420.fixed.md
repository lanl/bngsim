- **`bngsim.jax.differentiable_solve` integrated a molar model to a trajectory wrong by its own size with no warning** ([#1420](https://github.com/lanl/bngsim/issues/1420)). It declared `atol=1e-8` and passed that on, so `Simulator.run` read it as the caller's choice and suppressed #1379's `AtolScaleWarning`: #1361's binding model came back A(5000) = -8.7e-10, for 4.1e-10, and its gradient was taken through that trajectory. The default is `None` now, which is `Simulator`'s default with its warning, on the single-call and the chunked path alike; the trajectory and gradient are the same bits as before. `atol="auto"` is passed on as `run` takes it, where it raised before, and gives 4.142e-10.
