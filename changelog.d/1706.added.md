- **Example models with exact solutions, and `bngsim.ModelBuilder` for building a model in Python ([#1706](https://github.com/lanl/bngsim/issues/1706)).** `bngsim.examples` has six small models that ship with BNGsim: `binding` (A + B <-> C), `decay`, `chain`, `birth_death`, `bolus` (an event), and `schlogl` (a bistable switch). Each comes with its exact solution, `bngsim.examples.exact(name, t)` or `steady_states(name)`, so you can try BNGsim with no model file and check its answers. `binding` comes in every format: `.net`, BNGL, BNG-XML (for NFsim and RuleMonkey), SBML, Antimony, and Python. `bngsim.ModelBuilder` builds a model in Python: add parameters, species, reactions, observables, functions, and events, then `build()` returns a `Model`. The events guide's example used the internal builder and did not run; it now uses `ModelBuilder`.
