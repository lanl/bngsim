- **A forward-sensitivity run is refused around the tolerance where a
  state-dependent switch and an event are not told apart, not only at it.**
  The #945 refusal takes a switch's crossing time to be known to one step's
  tolerance, but a species whose rate changes carries what every step added
  to its error: `V = e^(2t)` was 39 to 185 times one step's tolerance out at
  t = 3, its switch was found before an event it follows by 1.99e-5, and at
  rtol 2e-6, 1.1e-6, 9e-7 and 5e-7 the run returned dW/dtau = −1.05 for
  −3.15 with no error. The reach now counts the relative tolerance twice for
  every step taken, for a species whose rate changes as the run goes; a
  linear one, which the run has exactly, keeps one step's. An event whose
  trigger is on the state has a reach of its own, counted the same way, and
  the two are judged apart by the sum: an event on U = e^(c·t) 5e-7 after a
  switch on V = 2t returned dW/dc = 9.45 for 3.15 at rtol 2e-7 and 3e-7.
