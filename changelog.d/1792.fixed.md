- **`sbml_to_net` and `sbml_to_bngl` wrote a parameter that was folded into a number when the SBML loaded (`Model.frozen_params`) as a free one ([#1792](https://github.com/lanl/bngsim/issues/1792)).** The model loaded from the file took `set_param` on it, where the SBML model refuses: with no effect where nothing else read the parameter (BIOMD0000000040's `f`, a stoichiometry: Br(5) stayed 0.026263 for 0.0394), and with half an effect where a rate law still did. A frozen parameter that nothing in the written network reads is now left out, with a `dropped` note, so `set_param` on it fails in bngsim, and a `setParameter` in BNG2.pl. One that is still read is written with a `folded_at_load=` comment on its line, which `Model.from_net` and `Model.from_bngl` read back into `frozen_params`, so the reloaded model refuses the write too; these are listed under `bngsim_only`, since another reader of the file takes each as free. A parameter that actions written beside the file read stays in it, marked. The report names both kinds in `folded_left_out` and `folded_marked`, and `omex_to_net` notes an action that sets or scans either. Networks without such a parameter are written as before.
