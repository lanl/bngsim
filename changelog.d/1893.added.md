- **`Result.check()` now checks a run's forward sensitivities (issue #1893).**
  It used to judge the trajectory alone, so a wrong `dY/dθ` column passed. A
  run made with `sensitivity_params=` or `sensitivity_ic=` now gets a
  `"sensitivity"` check by default: the sensitivities of the tolerance check's
  run, judged series by series on each one's own peak and the absolute
  tolerance the solver held it to. `check("all")` adds `"sensitivity_fd"`: a
  difference quotient of runs made with the sensitivities off, which widens
  itself near a switch or event time a parameter moves. Each verdict names the
  worst series, the worst species of each column, and the series the run does
  not resolve. `check("all")` on a sensitivity run no longer reports the
  `backend` check as an exception.
