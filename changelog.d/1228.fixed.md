- **A sensitivity run whose rate law branched on an equality the state sat on returned 0 for the columns of whatever ended it, with no error** ([#1228](https://github.com/lanl/bngsim/issues/1228)). `if(Bobs==0, kb, 0)` with B held at 0 until A falls to q gave dY/da and dY/dq as 0 for -6.44 and -1. An equality is rooted only where it is crossed, and either side of its surface reads false, so leaving a surface the state sat on was a switch nothing saw; `Bobs<=0`, the same switch, is located and refused at its tangency. A rate-law equality (or `!=`) over state that the run starts on and stays on is now refused by name, pointing to the crossing that ends it or an inequality. An equality the state starts on and leaves at once, or only crosses, or that no rate law reads, runs as before.
