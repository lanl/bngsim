- **SSA and PSA started a concentration species from its count at the compartment's load-time size, where its starting size had been written ([#1463](https://github.com/lanl/bngsim/issues/1463)).** With `set_concentration("c", 3)` on an event-resized compartment loaded at 2, `X = 50` started at 100 molecules for 150 and stayed low by 3/2; the same for a rate-rule compartment, and for one an assignment rule sizes from a parameter that was written (`c := V0 + time`). A run that starts from the model's concentrations now counts them at the size the compartment has at its start. A run that goes on from where an SSA run left the model (a second `run`, `run_until`, `run_replicates`, `save_concentrations` and `reset`, a named snapshot, a clone) keeps the counts it left, and an SSA run after an ODE run counts the ODE's concentrations at the size then.
