- **`Model.from_biomodels` loads a BioModels entry by its id ([#1706](https://github.com/lanl/bngsim/issues/1706)).** `bngsim.Model.from_biomodels("BIOMD0000000010")` asks BioModels for the entry's main SBML file, checks it against the sha256 BioModels publishes, and keeps a copy in `~/.cache/bngsim/biomodels` (or `$BNGSIM_BIOMODELS_CACHE_DIR`), so the next call needs no network. Pass `version=` to pin a version. `model.describe()["source"]` records the id, version, file name, and sha256. With no network and no cached copy, the error says so and names the cache directory. `Model.load("BIOMD0000000010")` used to read the id as a file with no suffix; it now says to call `Model.from_biomodels`.
