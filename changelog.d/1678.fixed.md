- **`net_to_omex(bngl=<absolute path>)` wrote that path into the archive's SED-ML annotation ([#1678](https://github.com/lanl/bngsim/issues/1678)).** An archive made to be shared carried the exporter's directory names, a user name among them. The protocol's `source` is now written as the file's name alone, in every SED-ML document `write_sedml_protocol` writes, so `read_sedml_protocol` reads back `m.bngl`, not the path it was exported from.
