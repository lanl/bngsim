- **`Model.set_concentration` and `get_concentration` took only a species name exactly as the network writes it, where BNG2.pl's `setConcentration` finds the species ([#1833](https://github.com/lanl/bngsim/issues/1833), and the first case of [#1480](https://github.com/lanl/bngsim/issues/1480)).** BNG2.pl reads the name as one complete species and sets the one that is the same graph. `"A(y,x)"` for `A(x,y)`, a complex with its molecules in another order or other bond labels, `"@c:A()"` or `"A()@c"` for `@c::A()`, and a bare `"C"` for a molecule with no components raised `ModelError`, so a caller replaying a model's actions through the two methods could not run the model. Both methods now find that species, after the exact name. A name BNG2.pl aborts on (a component or state left out, a wildcard, an observable's name, a compartment before the name that the molecules' own contradict) is refused as before, but for a space inside or after a name and a `$` before its compartment; an SBML model's species are found only by id. The action replay uses the same lookup, so a complex written another way is set, and no longer counts as a dropped change.
