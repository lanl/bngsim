- **An ODE run with events evaluates the model once less per output row
  (issue #1183).** #1133's read-ahead, which reads the event triggers half a
  root tolerance past each row of a run with events and no sensitivities,
  synced the model at the state ahead and then fully again at the row's own
  state, before the row's recording evaluated it once more. It now puts back
  only the row's species, and the recording's own refresh does the rest. Runs
  are bit-identical; on 20001-row grids BIOMD0000000613, MODEL1710030000 and
  BIOMD0000000480 run 1.13-1.26x faster.
