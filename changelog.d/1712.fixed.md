- **`Model.load` on BioNetGen's XML, the file NFsim and RuleMonkey read, gave an empty model with no error ([#1712](https://github.com/lanl/bngsim/issues/1712)).** The file's `<sbml>` root is in `http://www.sbml.org/sbml/level3`, which is no SBML namespace. libSBML reports error 20101 and reads no model from it, but bngsim refused only fatal errors, so it built `Model(species=0, reactions=0, observables=0, parameters=0)`, which ran and returned nothing. `Model.load`, `Model.from_sbml` and `Model.from_sbml_string` now refuse a document whose root is in no SBML namespace. BioNetGen's XML is named for what it is, with the routes that run it: `NfsimSession` or `RuleMonkeySession` on the file, or `xml_path=` beside the model loaded from its `.net`. Of the 4,359 XML files in the repository and the BioModels corpus, the 125 that give error 20101 are all BioNetGen XML.
