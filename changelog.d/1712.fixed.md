- **`Model.load` on BioNetGen's XML, the file NFsim and RuleMonkey read, gave an empty model with no error ([#1712](https://github.com/lanl/bngsim/issues/1712)).** Its `<sbml>` root is in `http://www.sbml.org/sbml/level3`, which is no SBML namespace, and the elements in its `<model>` are not SBML's: libSBML reports error 20101 and reads the `<model>` element but nothing inside it, so bngsim built `Model(species=0, reactions=0, observables=0, parameters=0)`, which ran and returned nothing. `Model.load`, `Model.from_sbml` and `Model.from_sbml_string` now refuse an empty model that is BioNetGen's XML (told by `<ListOfMoleculeTypes>` or `<ListOfReactionRules>`) or whose root is in no SBML namespace. BioNetGen's XML is named, with the routes this build has that run it: `NfsimSession` or `RuleMonkeySession` on the file, or `xml_path=` beside the model from its `.net`. SBML with a missing or slightly wrong root namespace, whose model libSBML reads whole, loads as before. Of 4,359 XML files in the repository and the BioModels corpus, the 125 refused are all BioNetGen XML.
