- **On Debian-based slim images `Model.from_bngl` failed with Perl's "Can't locate FindBin.pm", and BNGL loading was reported available ([#1761](https://github.com/lanl/bngsim/issues/1761)).** The `perl` there is `perl-base`, without the core library that BNG2.pl's line 34 (`use FindBin`) and its `Perl2` modules load, and the check for a usable BioNetGen asked only whether some `perl` was on `PATH`. It now asks that perl to compile the BNG2.pl it found (`perl -c`, once per script and perl, cached), so `HAS_BNGL`, `capabilities()["missing"]["bngl"]` and `from_bngl`'s refusal agree and say the same thing: which module Perl could not find, in Perl's own words, and the fix, `apt-get install perl`. A found BNG2.pl with no perl at all is reported as before.
