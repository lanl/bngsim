- **A second `run()` continued the first run's end state with its clock set back, and its Result said nothing of it ([#1701](https://github.com/lanl/bngsim/issues/1701)).** `A -> B` run twice over `(0, 5)` from `A = 10` gave `A(0) = 10`, then `0.0674`. The behaviour stays, as BNG2.pl's has it, and is now recorded and checked:
  * `Result.started_from` (`"initial"` or `"live"`) and `Result.start_state_sha256`, also in `summary()`, `save()` and `to_xarray()`.
  * A `bngsim.LiveStartWarning` before a call starts from exactly the state the last run left, before the time it ended at: `run()`, `run_until` (by its clock), `run_replicates`, `parameter_scan`, `bifurcate`, and `run_protocol`'s first run.
  * `run(start="initial")` resets the model first, undone if the run raises; `run(start="live")` continues without the warning.
