- **On a slim container image, every SBML and Antimony load failed with a bare `ImportError: libexpat.so.1` ([#1760](https://github.com/lanl/bngsim/issues/1760)).** python-libsbml's Linux wheel reads the system expat library, which images such as `python:3.13-slim` do not ship, so `import libsbml` fails inside the package while `import bngsim` and `.net` models work, and `capabilities()` still reported SBML as available, since `HAS_LIBSBML` only looked the package up. The loader's import now raises a message that says python-libsbml is installed but its compiled module did not load, quotes the cause, and names the fix, `apt-get install libexpat1`, keeping the exception's kind and `name`; `Model.from_sbml` and `Model.from_antimony_string` now name the cause and the fix too. `bngsim.HAS_LIBSBML` and `capabilities()` try the import, lazily like `HAS_BNGL`, so they read `False` there with the same text; the flag is probed when read, so assigning it no longer changes `capabilities()`. An antimony that is installed but cannot load is relayed with its cause instead of the extra's install hint. The installation page says what slim images need.
