- **An event on the rateOf of a species whose own rate is a rateOf fires where
  it should (issue #991).** The trigger root function took the rateOf buffer
  from the right-hand side, which probes only as deep as the derivatives read
  rateOf, and a trigger can read one level deeper. `at (rateOf(X0) > 0.3)` with
  `X0' = rateOf(X3)` never fired at a smooth crossing (t = 0.45), and
  `at (rateOf(S) > 0.5)` with `S' = rateOf(A)` fired at t = 0 on an unrelated
  species' rate. The trigger now reads the buffer at the model's full depth.
