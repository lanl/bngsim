- **A table function added over a function that was already analyzed is seen** ([#979](https://github.com/lanl/bngsim/issues/979)). `Model.add_table_function("drive", ...)` on a model with a function `drive` makes the compiled code read `drive` from the table. The memo of the output-sensitivity analysis was keyed by the number of functions and by no table, so a model that had run a sensitivity before the table was added kept its analysis: `d drive/dk = 1` and `dg/dk = 0.5` for `g = drive*a` came back for a `drive` the code no longer computes from `k`. The key has each table function with what it is read over, and the selector raises with the reason.
