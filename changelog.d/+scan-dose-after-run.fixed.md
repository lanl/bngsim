- **`parameter_scan` over a parameter that seeds an initial condition dropped the dose after a run, and no warning said so.** Each point starts from the state at the call, and a parameter write moves a species only while it sits on its initial condition: a scan over A0 = 5 and 40 after a run started both points at the run's A = 6.07 (found on [#1643](https://github.com/lanl/bngsim/pull/1643)). The scan keeps that start, which a pre-equilibrated protocol relies on, and now warns, naming the species it does not move, through a derived initial condition too (`A = A0*s`), a compartment size and after `save_concentrations()` with no label; in a sensitivity scan, where no write moves a species, it names every species the parameter seeds. The warning, a `ScanDoseWarning`, names `Model.reset()` first, for a dose scan from the initial conditions (outside a sensitivity scan, which refuses that start), and an `on_point` hook, to dose from the current state. Where the scan also raises `LiveStartWarning`, that warning no longer offers `save_concentrations()`, which would not dose them. Each Result records the dose warning in `notices` as `scan.dose_dropped`.
