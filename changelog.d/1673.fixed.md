- **An ODE row on the instant a counter reaches an event's threshold read the state before or after the event according to the run's length ([#1673](https://github.com/lanl/bngsim/issues/1673)).** `x(0) = 0.1`, `x' = 1`, `at (x >= 2.6): S = 1`: the row at t = 2.5 read S = 3 for `t_end` in (2.5, 4] and (32, 64], and S = 1 for (4, 32], with nothing else changed. The crossing time came from a two-point solve over a power of two at or above the run's end, which in doubles moves by an ulp with that scale. It is now moved to the first double at which the trigger's residual, as the doubles evaluate it, is 0 (or the nearest where none is), so the stop and the row are the same for every run length, and the row holds the state after the event, as a row on an event's instant does (#1124). A threshold off the row is unaffected.
