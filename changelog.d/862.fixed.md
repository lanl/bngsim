- **NFsim no longer fails obscurely on a rate law that reads `time()`
  (issue #862).** `method="nf"` failed at setup with `Error preparing function f
  in class GlobalFunction`. `Simulator` and `NfsimSession` now raise `ModelError`
  naming each function that reads `time()` (or a bare `time`) and pointing at
  `method="rm"`, `"ode"` or `"ssa"`, which run it. NFsim still runs a table
  function indexed by time (see issue #892). RuleMonkey's half of this issue,
  where such a rate never fired and every row was the initial state with no
  warning, is fixed by the RuleMonkey 3.11.0 re-vendor (#1022). From @Montana.
