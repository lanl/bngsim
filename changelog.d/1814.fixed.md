- **A forward-sensitivity run failed to build under clang when the generated C
  nested brackets more than 256 deep (issue #1814).** A table of daily values
  written as a chain, `if(time()<=1, v1, if(time()<=2, v2, ...))`, got two
  brackets deeper per `if()`, past clang's limit at 128; a plain run fell back to
  the interpreter. An `if()` that is all of another's false branch is now the
  next link of one flat `?:` chain, which computes the same values, and clang is
  given `-fbracket-depth` for a source still deeper than 256, such as a chain
  through the true branches; any other build's command is unchanged. A chain of
  about a thousand, which every codegen build refused with a `RecursionError`,
  builds too. From 99 `if()`s the analytic sensitivity RHS is still not built:
  the run uses CVODES' difference quotient where the conditions allow it, and
  refuses as before where they read the state. A failed build now says it was
  the compiled right-hand side.
