- **A forward-sensitivity run failed to build under clang when a function
  nested 128 or more `if()`s (issue #1814).** Each `if()` of a chain such as
  `if(time()<=1, v1, if(time()<=2, v2, ...))`, a table of daily values, went
  into the generated C two brackets deeper than the last, past clang's limit of
  256; a plain run fell back to the interpreter. An `if()` that is all of
  another's false branch is now the next link of one flat `?:` chain, in the C
  and in the `Piecewise` text sympy parses, whose limit of 200 parentheses had
  declined the analytic sensitivity RHS from 99 `if()`s on. Values are
  unchanged.
