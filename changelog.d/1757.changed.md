- **A pull request that adds tests no longer has to raise a count in `ci/test_floors.env` ([#1757](https://github.com/lanl/bngsim/issues/1757)).** The Python suite counts job now holds each test file's collected and skipped counts, for `python/tests` and `parity_checks/tests`, to the same leg's counts on main (`ci/test_file_counts.py`): a file the change does not touch may not lose a test, and untouched files may not gain more than 10 skips. A deliberate loss is accepted with the `drops tests` pull request label. The four bounds this replaces, and the merge conflicts two pull requests adding tests at once had over them, are gone.
