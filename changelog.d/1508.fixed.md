- **The Antimony loaders built the last module defined, not the main one ([#1508](https://github.com/lanl/bngsim/issues/1508)).** `Model.from_antimony`, `Model.from_antimony_string`, `Model.load` on a `.ant` and an Antimony `EvaluationSpec` took `getModuleNames()[-1]`. Top-level reactions beside a helper `model`, a `model *main()` defined before another, and a module instantiated at top level with an override (`A: sub(); A.k = 0.5`) each loaded the other module, with no word: S1(2) = 0 or 8.187 for 3.679. They now load the module libantimony names main, as RoadRunner does. A stray top-level statement before or after the model still loads the model, with a `ConversionWarning` naming any symbol it leaves out. The RoadRunner reference side of the comparisons, which took the last module too, now reads the main one.
