- **A run that fails keeps its notices on the error ([#1857](https://github.com/lanl/bngsim/issues/1857)).** A `BngsimError` raised by a run now carries the notices the run had collected, as `e.notices` and in `e.to_dict()`: that it started from the last run's end state, say, or retried on a difference-quotient Jacobian. A warnings filter or logging level does not drop them. An error raised from a run's error carries that run's notices too, and a sensitivity chunk that fails and is retried column by column passes what it noted on to the result.
