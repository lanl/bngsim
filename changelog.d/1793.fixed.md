- **`mratio(a, b, z)` no longer returns a wrong value when `a` is a tiny
  positive number below a `b` under 1 and `z` is past -20 (issue #1793).**
  The continued fraction still ran there and lost up to all of the ratio:
  `mratio(1e-30, 2e-12, -3e4)` returned 7.047e-17 for 6.667e-17, and some
  answers had the wrong sign. The corner issue #1080 sums as two series out to
  `z = -700`, and leaves to the asymptotic expansion beyond, is now
  `0 < b - a < 1` with `b < 1`, which takes these too. The worst error there is
  now 2.7e-14. Both engines. BNG's own arguments are unaffected, bit for bit.
