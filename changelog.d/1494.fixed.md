- **`Model.from_bngl` served a stale network after a file the model reads was edited** ([#1494](https://github.com/lanl/bngsim/issues/1494)). The network cache was keyed on the `.bngl` text and the BNG2.pl file only. A model that reads a parameter set with `readFile({file=>..., blocks=>["parameters"]})` before `generate_network` kept the first network: after the file went from k = 1 to k = 2, the load still had k = 1 and A(1) = 36.79 where 100·exp(−2) = 13.53, with no warning. `Model.load` and `run_bngl` went the same way. A model that calls `readFile`, `readModel`, `readNetwork`, `readSBML` or `readNFspecies` before `generate_network`, in the actions or inside `begin model`, is now generated afresh on every load. The key also covers the `Perl2` library and `VERSION` BNG2.pl loads, which `$BNGPATH` can take from another install and a BioNetGen checkout edits in place. BNG2.pl now runs from the model's directory, so a relative `readFile` path, which was refused, resolves there; a relative `$BNGPATH` is passed to it made absolute.
