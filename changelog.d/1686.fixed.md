- **The SED-ML written from a BNGL protocol had no data generators and no outputs ([#1686](https://github.com/lanl/bngsim/issues/1686)).** It did not say what any experiment reports, and nothing told its experiments from their parts: a run / add / run protocol wrote five tasks, three of them pieces of a chain. Each experiment now has a report, of the time and the model's observables (its species where it has none), read from the task that runs it; that of a run that continues earlier ones holds their rows first. `bngsim-net2sbml --sidecar` passes the network, so its reports name the observables.
