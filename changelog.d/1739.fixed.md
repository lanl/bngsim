- **`read_sedml_protocol`, reading a document's standard elements, dropped, repeated or reordered runs where chains shared their first runs ([#1739](https://github.com/lanl/bngsim/issues/1739)).** `write_sedml_protocol` writes a run that continues earlier ones as a chain that replays them, and the reader dropped every task whose steps were the start of another's. So `simulate; simulate; resetConcentrations(); simulate` read back two runs of three; a scan, `saveConcentrations()`, a run, `resetConcentrations()`, `setConcentration` and a run read back the scan twice; and a run continuing a saved state after an unrelated run read back before it (t_end 2, 1, 3 for 1, 2, 3). None was reported lossy. Each task is now read once, in order, from where the tasks before it left the model, from a state they reached earlier (saved there, with `saveConcentrations` and `saveParameters` under a label of its own), or from the initial state, and replays to the bit what the annotation's protocol runs.
