- **`save_concentrations()` cleared the carried-over mark of a state a run had advanced, so the next sensitivity run started from `dx(0)/dθ = 0` with no error ([#1528](https://github.com/lanl/bngsim/issues/1528)).** A sensitivity run on such a state with no carried `dx/dθ` raises, since the state is `x(θ)`. With a save in between, taking "no seed" for "literal initial conditions", it returned `dA(0)/d(kp, kd) = [0, 0]` where the closed form is `[2, -8]`: equilibrate, save, measure, and the dose that `set_concentration`'s docstring says to save. `reset()` to that baseline, a named snapshot or a `Simulator.snapshot()` of it restored, a clone of it, `run_batch` rows from it and `steady_state(sensitivity_params=...)` on it did the same. The save now keeps the mark, the baseline and both kinds of snapshot keep it for `reset()`, the restores and `clone()`, and all of these raise as the live state does. A save of a state no run advanced, such as `set_concentration` doses on a fresh model, is still literal initial conditions. So `differentiable_solve` after a run and a save, which #1521's warning offered as a start with derivative 0, now refuses.
