- **`save_concentrations()` cleared the carried-over mark of a state a run had advanced, so the next sensitivity run started from `dx(0)/dθ = 0` with no error ([#1528](https://github.com/lanl/bngsim/issues/1528)).** Without the save such a run raises, since the state is `x(θ)`; with it, it returned `dA(0)/d(kp, kd) = [0, 0]` for `[2, -8]`: equilibrate, save, measure, and the dose `set_concentration`'s docstring says to save. `reset()` to that baseline, a named snapshot or a `Simulator.snapshot()` of it restored, a clone or `make_subset_model` of it, `run_batch` rows from it and `steady_state(sensitivity_params=...)` on it did the same. The save now keeps the mark, the baseline and both kinds of snapshot keep it for `reset()`, the restores and `clone()`, and all of these raise. A save of a state no run advanced, such as `set_concentration` doses on a fresh model, is still literal initial conditions. So `differentiable_solve` after a run and a save, which #1521's warning offered as a start with derivative 0, now refuses, and so does `sensitivity_ic` from a restored snapshot of an advanced state, where a later `set_param` of an initial-condition parameter no longer moves species.
