- **SBML→cBNGL carries a species an assignment rule sets, instead of refusing the model** ([#1400](https://github.com/lanl/bngsim/issues/1400)). `write_bngl` refused every such model, saying the round trip "cannot carry the rule". The rule was carried, as the function its rate laws read; only the species' own column was lost. Written `$`-fixed, it was held at its initial value by BNG2.pl and by bngsim reloading BNG2.pl's `.net`, whose pattern name (`@comp1::$B()`) never matched the rule's. The writer now names the molecule after its rule (`__ar_B`), bngsim's reader pairs the two, and `validate="bng2"` checks that column as well as the right-hand side (`max_ar_report_delta`). The species is a `bngsim_only` warning, as on the `.net` path, because BNG2.pl's own run still holds it. Of the corpus's 289 models with such species, 175 are no longer refused for it, and 174 of those pass the `bng2` gate. The gate catches the one that does not: BIOMD0000000664 reports a rule species differently at t = 0. A model with no reactions, which BNG2.pl's `generate_network` aborts on, is now refused by name.
