- **A `.net` Hill law with 0 < h < 1 failed every run that reached zero substrate ([#1497](https://github.com/lanl/bngsim/issues/1497)).** The loader rewrites `Hill Vmax Kh h`, which BNG2.pl writes for `Hill(Vmax,Kh,h)` in BNGL, as `Vmax*S^(h-1)/(Kh^h+S^h)` times S. That is `inf*0`, a NaN, at S = 0, where the law and run_network give 0. So ODE runs, interpreted and compiled, failed with `CV_FIRST_RHSFUNC_ERR`, SSA and PSA stopped at the last substrate molecule, and `Model.rhs` returned NaN. Where h is in (0, 1), or is an expression parameter, the rewrite is now guarded so that the function is 0 for S <= 0 while h is in (0, 1). It reads as before at every S > 0, and an h known at load to be >= 1 or <= 0 keeps the bare body. Runs from S = 0 match the closed form and run_network, and a run that drains S reaches its absorbing state, where run_network fails. The load warning's advice now writes the law in that guarded form.
