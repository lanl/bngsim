- **Wheels for CPython 3.14 and 3.15 ([#1491](https://github.com/lanl/bngsim/issues/1491)).** `pip install bngsim` on either version took the sdist and built from source, needing a C++ toolchain and CMake, and SuiteSparse for the KLU solver. The wheel matrix now covers cp314 and cp315 on Linux x86_64, macOS arm64 and x86_64, and Windows x86_64, and the classifiers, the installation page, the support matrix and `scripts/local_ci.py matrix` say so. `pypa/cibuildwheel` moves from v4.1.0 to v4.3.5, which builds 3.15 by default against a final release, 3.15.2. Free-threaded builds (`cp314t`, `cp315t`) are not included.
