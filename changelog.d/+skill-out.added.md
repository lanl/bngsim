- **`bngsim skill --out FILE` writes the agent guide as a `SKILL.md` file itself, and the README says where to put it.** For Claude Code, `bngsim skill --out ~/.claude/skills/bngsim/SKILL.md` installs it for every project. `--out` makes the folder, writes the same UTF-8 bytes the command prints, and expands a leading `~` even where the shell does not. A redirect (`bngsim skill > FILE`) still works in a POSIX shell, but Windows PowerShell 5.1 reads it in the console's code page and writes it as UTF-16. `bngsim guide --out FILE` writes the guide the same way.
