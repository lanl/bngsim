- **A bngsim built where the compiler targets a CPU with a fused multiply-add rounded CVODE's arithmetic differently from a baseline x86-64 build, so results on a numerical knife edge could differ between builds of the same source ([#1582](https://github.com/lanl/bngsim/issues/1582)).** Ubuntu 26.04's compilers default to x86-64-v3, and Apple's compiler fuses on arm64. There, a step size collapsing at a discontinuity, a march sliding along a switch surface or a steady state at its tolerance could come out the other way. All of bngsim's C and C++, SUNDIALS and the KLU it builds included, now compiles without floating-point contraction, as the generated C already did, so its arithmetic rounds as in a baseline x86-64 build. macOS results can change in the last bits.
