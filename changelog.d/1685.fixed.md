- **bngsim could not replay an archive it wrote when an action named a species with a component, a state or a compartment ([#1685](https://github.com/lanl/bngsim/issues/1685)).** The archive's protocol names `L(r)` as the BNGL file does, and its SBML has the id `L_r`: `run_protocol` on `load_model()` and `load_full_protocol()` raised, and `omex_to_net`'s actions file stopped BNG2.pl. `read_sedml_protocol(..., sbml=)` and `load_full_protocol()` now name each species and parameter by the SBML's id, so the protocol runs on the master model; `load_full_protocol(entry)` names them as another model entry does, the bundled `.net` by their BNGL names.
