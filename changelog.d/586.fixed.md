- **The API reference renders every `Simulator` signature and the `set_param` and
  `restore_concentrations` docstrings (issue #586).** The `atol=` type spelled
  `NDArray` as a forward reference, which autodoc looked up in `bngsim._simulator`
  and could not resolve, so nine signatures were left unrendered, and three
  docstring passages broke out of their field lists. A `docs` job in `lint.yml`
  now builds the documentation with `sphinx-build -W` on every pull request.
