- **The calls a caller brings from libRoadRunner, Tellurium, SciPy or BioNetGen name bngsim's call ([#1700](https://github.com/lanl/bngsim/issues/1700)).** `Model(path)` and `Simulator(path)` failed inside bngsim (`'str' object has no attribute 'param_names'`); they now say to use `Model.load(path)`. `sim.simulate`, `sim.reset`, `bngsim.load`, `Model.from_file`, `result.to_dataframe()` and other foreign names, and `run(0, 10, 11)`, `run(t_end=10)`, `run(n_steps=10)` and `run(times=[...])`, raise the error Python raised, now naming the call to make. None is an alias: BioNetGen's `n_steps=10` is `n_points=11`. `ParameterError` lists close names, and says when a name is a species or an observable. `result.species["A"]` is species A's column, as `result.observables["A"]` is. The table is `bngsim._foreign_names.FOREIGN_NAMES`.
