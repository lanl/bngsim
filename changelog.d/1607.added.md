- **A source build can read SUNDIALS from a local copy instead of downloading it
  (issue #1607).** Set `BNGSIM_SUNDIALS_ARCHIVE` to a copy of the pinned
  `sundials-7.2.1.tar.gz` and the build reads that file. It is still checked
  against the pinned sha256 and patched as the download would be. A name that is
  not a file falls back to the download, with a warning. CI uses this to keep the
  archive in its cache, so an outage of GitHub's release downloads no longer
  fails every build.
