- **The "New test files run somewhere" check no longer counts a new file as run where a later change to it would run it nowhere, and no longer drops a quoted pytest pattern ([#1861](https://github.com/lanl/bngsim/issues/1861)).** A file added to `mir.yml`'s pytest list but not to its paths filter counted as run, though a later change to the file alone fires no workflow that runs it; it is now warned about, and `mir.yml` and `windows-tail.yml` gain the three test files each ran outside its own filter. A quoted `--ignore-glob` pattern or `--deselect` node id is kept as the option's argument, `--ignore-glob` is matched with fnmatch as pytest matches it, directories included, and a quoted node id selects its file. A paths filter with `?`, `+` or `[` is not evaluated, since GitHub reads those differently from bash, and a `git diff` that fails is a warning rather than a red job.
