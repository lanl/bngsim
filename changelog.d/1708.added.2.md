- **`bngsim run MODEL` and `bngsim check MODEL` (issue #1708, part 2).** `run` makes one run from the model's initial state and prints the run's record and `Result.digest()`, never the arrays: `--out` writes those to `.npz`, `.csv` or `.h5`. `check` makes the same run, then `Result.check()`, and exits 6 when the check is not ok, with the report on standard output. Both take the method, the time window or sample times, `--set NAME=VALUE`, a seed and the tolerances; `run --replicates N` digests a stack of stochastic runs. Every run has a wall-clock limit, `--timeout` (600 s by default; exit 5 past it). A `.bngl` file needs `--network`, so the caller says it means one run of the generated network and not the file's own actions.
