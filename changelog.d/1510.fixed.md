- **After a run, an assignment-rule species read its starting value through the model ([#1510](https://github.com/lanl/bngsim/issues/1510)).** `Model.get_concentration`, `Model.get_state`, `Simulator.get_state`, `ReactionKernel.get_state`, `CouplingMap.read` and `Simulator.snapshot` returned a rule target at its t=0 value when the rule was linear in species (`S := 2*A` read 20 where the rule gives 2.706706), and for every rule under SSA, while `Result.species` reported the live value. A run now leaves each rule target in the model at the value it reports for the last row. The slot is read by no rate law and no event, so what follows does not move: a continuation run and a `carry_sensitivities` pre-equilibration give the results they gave.
