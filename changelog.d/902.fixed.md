- **`differentiable_solve` gets the same discontinuity handling and
  sensitivity terms as `Simulator.run`.** The JAX bridge built its own solver
  options and called the bare integrator, so its value and its gradient both
  skipped what a `Simulator` run arranges. That meant no crossing stops for a
  rate law switched on time or a counter clock, no roots for one switched on
  model state, no switch-time or saltation jumps, and no initial-condition seed
  for a primary that reaches a species through a derived parameter. A window
  inside one step came back as if it never opened, and `dB/dR0` through
  `B() Rt`, `Rt = 3*R0` came back 0, with no warning. Both paths now run
  through `Simulator`. A call costs about 0.1 ms more on a small model.
