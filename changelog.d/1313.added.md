- **Two refusals bngsim makes by name now have types of their own: `SparseJacobianUnavailableError` and `CodegenDeclinedError`.** `force_sparse_linear_solver=True` on a model with no sparse Jacobian for KLU, and `codegen=True` on a model codegen declines, were a `SimulationError` and a `RuntimeError` that a caller could tell from a crash only by their text, so a reworded message turned a refusal into a failure. Each subclasses what was raised before, so an existing `except` still catches it, and a codegen *build* failure stays a plain `RuntimeError`. The path-agreement harness now reads both by type (issue #1313).
