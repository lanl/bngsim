- **`BNGSIM_CODEGEN_STRICT=1` makes a failed automatic codegen build an error (issue #1544).** The ODE RHS at or above `BNGSIM_CODEGEN_THRESHOLD` and the SSA propensity library fell back to the interpreter when their build failed, so a timing harness could measure the interpreter without knowing. A model codegen declines still runs on the interpreter, unless the toolchain is already known to be broken, which is checked first.
