- **A derived initial condition's sensitivity seed read `rint`, `mod` and `frac` as numpy does, not as the engine does, so its column was wrong from t = 0 with no error ([#1800](https://github.com/lanl/bngsim/issues/1800)).** `X0 = rint(p)*k` at p = 2.5 seeded dX/dk = 2 for 3: numpy's `rint` rounds a half to even, its `mod` is floored, and sympy's `frac` is `x - floor(x)`, where the engine's are `floor(x + 0.5)`, `fmod` and `x - trunc(x)`. The seed now reads them, and the `%` operator, as the engine does, as the compiled and JAX right-hand sides already did. So does a derived parameter's value where a crossing reads it (`frac` read wrong there; `rint` and `mod` did not evaluate, so the crossing was refused).
